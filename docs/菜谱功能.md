自身有三高及痛风史，所以在做饭时会一直纠结菜单怎么列，怎么吃比较好。另外咨询营养师后，开的一些营养餐的解读和怎么融入到日常的饮食中去。

第一个需求点是 记菜单，每天都要记录一些菜单，准备吃什么，有时很难确定吃什么。比较纠结。有时想直接从之前的菜单的组合中选择，或者参考营养师的建议可以从历史菜单中自动生成，或直接按我的历史饮食中生成菜单。
第二个需求点是 每餐的搭配问题，比如是糖尿病患者，我准备菜品时该如何选择，避免一些升糖快的食物，或者我有高血压，或者我即有高血压又有糖尿病等，如何综合考虑。
 一方面如果有营养餐方案，能输入营养餐的信息或者通过其他方式识别(智能识别可以作为二期)，通过营养餐上的总的值，然后分配到每餐的搭配。
