## 0. 一句话总流程

```
搭框架 → 过本地校验(无损体检) → 拉取/补数据(提案) → 人工核验 → 落 seed
  P0 ────────────┘                    P1 ──────┘         你 ────┘
```

- **本地脚本**（P0 全部 + USDA 采集 + cn_en 映射）：读本地文件，**秒级跑完**，无需联网、无需 key、**不用设时长**。
- **联网脚本**（只有 `scripts/data/nlc_cross.py`）：请求政府站，慢，**支持按条数/按时间限制**（见 §4）。

## 1. 基础数据分类（脚本处理哪些 seed）

预设数据分散在 `shared/src/commonMain/resources/seed/`，本管线处理其中 **5 个食材相关文件**：

| 类别 | 文件 | 内容 | 关联键 |
|---|---|---|---|
| **基础数据/元数据** | `ingredients.json` | 名/code/别名/单位/emoji/分类·特征标签 | `code` + `name` |
| **营养值** | `ingredient_nutrition.json` | 热量/宏量/纤维/钠钾钙/GI/嘌呤/饱和脂肪/胆固醇 | `ingredient`(=name) |
| **忌口·慢病** | `ingredient_care_rules.json` | 病种/生命阶段的 avoid/limit/recommend | `ingredient` + `category` |
| **忌口·人群** | `crowd_rules.json` | 高尿酸/高血压等人群忌口 | `crowd` + `ingredient` |
| **属性(忌口中间层)** | `ingredient_attributes.json` | 含酒精/加工果糖等属性标签 | `name` |

> 菜品(`dishes.json`)、字典(单位/分类)、药食同源 **不在本管线**，另议。

## 2. 执行顺序（推荐）

### 【一键·最常用】跑完整首校（建库→导入→导出→校验→体检报告）
```bash
python data-pipeline/verify_roundtrip.py
```
它内部**自动按序**调用 build_staging → import_seed → export_seed → diff → 校验门 → 富化 guideline，一步出：
- 控制台：`roundtrip 差异 N 处` + 各类 flag 条数
- 产物：`data-pipeline/首校体检报告.md`（**现有数据体检单**）、`data-pipeline/staging.db`

> 想看数据健康状况，跑这一条就够。改了 seed 后重跑刷新。

### 【分步·排查用】想单独看某一步
```bash
python data-pipeline/build_staging.py     # ① 建空 staging.db
python data-pipeline/import_seed.py        # ② 5个seed → staging(关联失败记flag)
python data-pipeline/export_seed.py        # ③ staging → 等价seed(输出 _export/·不覆盖生产)
python data-pipeline/verify_roundtrip.py   # ④ 完整校验(会重跑①②③)
```

### 【P1·拉取/补数据·本地零key】
```bash
python data-pipeline/collect_usda.py            # USDA补缺satFat+交叉校验→提案(_export/usda_collect_proposal.json)
python data-pipeline/build_cn_en_candidates.py  # 中→USDA映射候选→评审清单(mappings/cn_en_candidates_review.md)
```

### 【联网核对·可选·慢】
```bash
python scripts/data/nutri_selfcheck.py          # 能量自洽(本地·零联网·最快揪错)
python scripts/data/nlc_cross.py --limit 10     # nlc同口径交叉(联网·先小样本·见§4)
```

## 4. 跑多久的参数（按条数 / 按时间）

**本地脚本无需限制**（秒级）。**只有联网的 `scripts/data/nlc_cross.py` 慢**，支持两种限制，且**断点续连**（缓存已跑的，下次接着跑，不重来）：

| 参数 | 含义 | 例 |
|---|---|---|
| `--limit N` | **按条数**：只跑前 N 条 | `--limit 20`（跑 20 条验证） |
| `--max-seconds S` | **按时间**：跑够 S 秒即停 | `--max-seconds 120`（跑 2 分钟就停） |
| `--names A,B` | 只跑指定名（调试匹配） | `--names 糙米,大米` |
| （无参数） | 全量 502 条（cron 月度体检用） | `python scripts/data/nlc_cross.py` |

```bash
# 例：分多次跑满全量，每次跑 3 分钟，跑完自动接续
python scripts/data/nlc_cross.py --max-seconds 180   # 第1次
python scripts/data/nlc_cross.py --max-seconds 180   # 第2次(接着上次·缓存续连)
```

> 联网脚本自带 **0.3s/条友好限速**，不硬刷政府站。全量约需数分钟。

## 5. 改了数据之后（重要）

1. 改 seed（营养/忌口）→ 重跑 `python data-pipeline/verify_roundtrip.py` 看是否引入新问题。
2. 改营养/忌口 seed 后必跑工程单测：`scripts\build-cli.bat :shared:testDebugUnitTest`（含 `validateNutritionSeedForTest`）。
3. seed 内容一变，**指纹自动变**→老用户"更新基础数据"时自动 reseed（无需改版本号）。
4. **改数据前先看体检报告的"修复方法"**；忌口/营养属健康数据，改动要能溯源、不编造。
