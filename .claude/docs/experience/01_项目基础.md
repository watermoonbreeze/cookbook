# 项目基础

## 项目概况

[2026-05-14] Cookbook 是一款面向慢性病（三高、痛风等）患者的饮食规划 APP，解决"每天吃什么"的决策疲劳问题。

- **技术栈**：KMP（Kotlin Multiplatform），Android 端 Jetpack Compose，iOS 端 SwiftUI
- **包名**：`com.sxdbsm.cookbook`（shared），`com.sxdbsm.cookbook.android`（Android App）
- **Kotlin**: 1.9.20，**AGP**: 8.2.2，**Compose**: 1.5.4，**Material3**: 1.1.2
- **数据库**：SQLDelight（跨平台 SQLite），**DI**：Koin
- **最低 SDK**: 21，**目标/编译 SDK**: 34，**JVM Target**: 1.8

## 模块结构

[2026-05-14]

- `:shared` — 跨平台共享模块（Domain + Data 层），通过 expect/actual 适配各平台
- `:androidApp` — Android 应用（UI 层，Compose + ViewModel + Navigation）
- `iosApp/` — iOS 工程（SwiftUI）

## 开发阶段

[2026-05-14] 当前处于 **MVP 阶段**，聚焦三个核心功能：快速记录每餐、查看历史菜单、从历史中复用菜单。

产品规划路线：MVP（记录与复用）→ 一期（健康约束与营养方案）→ 二期（AI 智能推荐）
