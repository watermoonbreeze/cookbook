# Cookbook MVP 界面与功能方案

> 最后更新：2026-05-21（二审调整：热度规则改自动累加 + 删本餐评分 + NewDish 隐藏喜爱度 + 区分菜品查看/编辑）
> 配色规范见：`docs/技术栈与主题风格.md`
> 数据库设计见：`.claude/docs/feature/数据库设计方案.md`

## 核心原则

- 用户每天打开 APP 一个目的：**今天吃什么**。所有动作能少一步就少一步。
- 视觉调性：**绿色主调 + 蜂蜜橙暖色辅助**，避免冷感与医院风，中老年用户也亲和。
- 慢病人群提示靠**语义色板**（Success/Warning/Danger）独立维护。

## 二、配色与组件复用约定

### 关键约定

- **Primary 绿** = 主操作 / 餐次标题 / 主导航高亮
- **Tertiary 蜂蜜橙** = 品牌暖意强调（收藏、复用、导入、`#复制`、喜爱度星、装饰图标）
- **Warning 橙（更亮）** = 业务警告（中风险食材角标）。**不要与 Tertiary 混用**
- **Success/Warning/Danger** 三档 = 健康业务语义（人群推荐/慎食/禁忌）
- **Error 红** = 系统级错误（输入校验）。与 Danger 红区分使用场景

### 跨页复用 Compose 组件

| 组件 | 复用方 |
|------|--------|
| `DayMealCardView(data, isPlanState)` | HomeScreen 计划模块、FoodTimelineScreen 列表行 |
| `DishMiniCard(dish, size=80.dp)` | HomeScreen 热门/最近、DishesScreen 热度区、DayMealCard 内菜品横滑 |
| `IngredientChip(ingredient)` | NewDishScreen 食材清单、IngredientPickerScreen 选中态 |
| `DishRow(dish, mode)` | DishesScreen 主列表（Browse/Select 共用） |
| `EmptyState(icon, text)` | 各空数据态 |

### 缩略图占位策略

无图时：用 `dish.id` / `ingredient.id` 取 hash，从 `PrimaryContainer` / `TertiaryContainer` / `SecondaryContainer` 三色中选一色作背景，中央显示首字（白色 / Container 对应 On 色）。

### 排序 tab 逻辑

| Tab | SQL |
|-----|-----|
| 最近（默认） | `ORDER BY MAX(meal_record_dish.created_at via JOIN) DESC` |
| 喜爱 | `ORDER BY dish.preference DESC, dish.updated_at DESC` |
| 拼音 | `ORDER BY dish.name COLLATE NOCASE ASC` + 显示 A-Z 侧索引 |
| 全部 | `ORDER BY dish.created_at DESC` |

### 顶部"🔥 热度"横滑查询（2026-05-21 调整）

```sql
SELECT *
  FROM dish
 ORDER BY preference DESC, name COLLATE NOCASE ASC
 LIMIT :limit                       -- 默认 6
```

**说明**：
- `dish.preference` 是 0-100 的热度分，由 `trg_dish_popularity_after_insert` 触发器自动累加（每次菜品被添加到 `meal_record_dish` +0.1）
- 不再用时间窗口或次数阈值过滤，**按热度分排序即可**
- HomeScreen 的"🔥 热门"模块用同一查询
- 数据库存储一份持续累计的热度值，无需运行时聚合，查询效率 O(N log N)

- 点击 DishRow → 详情页（查看/编辑，本文档暂不展开详情页设计）
- 长按 DishRow → 菜单 [基于此另存] / [删除] / [取消]
- 右上 + 号（Browse）/ 弹框顶部"添加菜品"（Select）→ 启动 NewDishScreen

## 八、NewDishScreen（新建菜品 + 导入）

> **承担两种用途**：①新建菜品 ②编辑已有菜品（从 DishesScreen 详情页 [编辑] 进入）。两种用途**共用同一个 Composable**，由 `mode: New | Edit(dishId)` 参数控制顶部标题和保存逻辑。
