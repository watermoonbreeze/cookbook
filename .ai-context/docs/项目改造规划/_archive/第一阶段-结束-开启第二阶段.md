# 0. 任务目的

外部架构审核已经确认：

```text
Project Graph Phase 1

Model Contract
= FROZEN
```

4. 建立 Phase 1 → Phase 2 的不可遗漏承接记录；
5. 不实施任何 Phase 2 数据迁移。

# 6.1 Frozen 的含义

必须明确：

```text
Frozen
≠
永远不可修改
```

Frozen 表示：

> 后续 Phase 不得因为迁移数据方便而随意改变核心 Contract。

只有满足：

```text
发现通用模型无法表达真实项目需求
+
形成明确 Architecture Change
+
经过独立架构复审
```

才能修改 Frozen Contract。

禁止：

```text
DeepSeek发现某条数据不好迁
→ 顺手改Schema
```

# 7. 明确 mode:draft 与 Frozen 的区别

README 必须明确：

```text
Contract = Frozen
Graph mode = draft
```

### Contract Frozen

```text

```

```text
Cookbook 的真实项目数据尚未完整 Bootstrap，
Generated Views 尚未切换，
Project Graph 尚未成为当前唯一 Project Truth 入口。
```

因此：

> 本任务绝对禁止把 `mode` 改成 `active`。
