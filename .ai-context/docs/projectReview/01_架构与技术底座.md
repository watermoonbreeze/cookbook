## 概览层：架构心智模型

**整体架构** — Clean Architecture 简化版（UI / Domain / Data 三层），跨平台核心下沉到 `:shared`，平台 UI 各自实现。

- **`:shared`（commonMain/androidMain/iosMain）**：Domain（Model、UseCase）+ Data（Repository、SQLDelight）+ AI 运行时抽象 + 健康算法。用 `expect/actual` 适配平台。
- **`:androidApp`**：只负责 UI（Compose 页面、ViewModel、Theme、Navigation），依赖 `:shared`。
- **`iosApp/`**：SwiftUI 工程调 shared framework（**当前不交付，iOS target 注释**）。
- **数据流**：UI/ViewModel → Repository（返回领域模型，不暴露 DB 行）→ SQLDelight。Repository 经 Koin 注入；支持 Flow 响应式监听 + suspend 一次性读。

## 细节层：技术栈与规范

### 技术栈
| 项 | 值 |
|---|---|
| Kotlin / AGP | 1.9.20 / 8.2.2 |
| Android UI | Jetpack Compose 1.5.4 + **Material3 1.1.2**（版本受限，见 [06](06_约定与红线.md)） |
| 数据库 | SQLDelight（跨平台 SQLite） |
| 依赖注入 | Koin |
| 构建 | Gradle Kotlin DSL + 版本目录 `gradle/libs.versions.toml` |
| 包名 | `com.sxdbsm.cookbook`（shared）/ `.android`（App） |
| SDK | minSdk 21 / target·compile 34 / JVM 1.8 |

**预期行为** — 用 `scripts\build-cli.bat :androidApp:assembleDebug`（显式 JDK17）构建；单测 `scripts\build-cli.bat :shared:testDebugUnitTest`。直接 `./gradlew` 依赖全局 `org.gradle.java.home=jdk-17`。

### 依赖注入（Koin）
- 各 Repository、ViewModel、跨屏总线（`NewDishPrefillBus`/`IngredientCreateBus`/`IngredientJumpBus`）注册在 `androidApp/.../di/AndroidModule.kt`（总线为 `single` 单例，跨屏传参靠它）。

### 通用平台能力清单（非业务）
| 能力 | 说明 |
|---|---|
| 本地存储与合规 | 数据落 app 专属外部目录 `getExternalFilesDir(null)/cookbook/`（零权限）；DB 在 `db/cookbook.db`（非默认 `databases/`）。图片存相对文件名 |
| 权限 | 采用 app 专属目录后已移除 `MANAGE_EXTERNAL_STORAGE`/WRITE/READ；拍照需运行时 CAMERA |
| 日志 | `AppLogger`（logcat + 文件 `log/yyyy-MM-dd.log`）；shared 高频诊断用 `CookbookDiag.log`（lambda 延迟、默认关） |
| 备份/导出 | `.ckbk` 打包 DB+图片+manifest；SAF 导出导入；局域网双设备同传（见 [02](02_业务流程全景.md) 流程 11） |
| AI 运行时 | `AiRuntime` 抽象：云端（智谱/DeepSeek/通义/月之暗面）+ 规则兜底 + 端侧占位（`OnDeviceAiRuntime` 待接 LiteRT-LM） |
| 计时/闹钟 | `AlarmManager.setExactAndAllowWhileIdle` + Receiver 保证息屏响铃；前台服务 IMMEDIATE |
