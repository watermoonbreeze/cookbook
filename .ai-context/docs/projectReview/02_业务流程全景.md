## 流程地图（依赖关系）

```
食材库 + 菜品库 + 健康档案 → 记一餐 → 食历 → 营养评估(今日卡)
                                 ↓            ↓
                            库存推荐 ← 库存   周期规划 → 采购清单
                                 ↓            ↓
                              记一餐  →  导出备份 / 双设备同步
```
分层：**基础**（食材→菜品→记一餐→食历）·**分析**（营养评估/慢病提示/缺口）·**推荐**（库存+历史+忌口+缺口→推荐）·**计划**（周期规划→批量记录/采购）·**持久化**（备份/同步）。

## 核心流程

### 1. 记一餐（核心 MVP）
**一句话** — 快速记录某日某餐吃了哪些菜，建立饮食历史。
**预期行为** — 保存后该餐进食历；新记（非编辑/搬运）会升相关菜喜爱度。
入口：首页新增/计划卡、食历"今天"、食材详情"记这道菜"。步骤：选日期→选餐次+时间+菜（可复用收藏/常吃/最近）→备注→保存（编辑改日期=移动删旧）。页面：`AddDayFoodScreen`/`DishPickerScreen`。数据：读 `meal_record`/`dish`/`meal_type`/`dish_favorite`，写 `meal_record`/`meal_record_dish`/`dish.preference`。关联：上游食材·菜品·收藏·档案；下游食历·营养·推荐去重·备份。**已知坑→[05](05_诊断地图.md)**：还原/撤销/搬运勿重复抬喜爱度。

### 1A. AI 快捷记一餐（多天自然语言）

**一句话** — 将用户输入的多天餐食文本、粘贴内容或语音转写为可编辑预览，再按确认结果保存到日期或一周计划。
**预期行为** — 预览前零写库；AI 成功结果明确标“AI 解析”，失败/未配置则保留原输入并显式提示“规则解析”，由用户确认后才入库。

入口：`AddDayFoodScreen` 顶栏 AI 按钮。步骤：输入→AI Runtime 结构化解析（或规则模板）→日期锚定/Schema 校验/规范化→`MultiDayRecorder.previewAll`→`DayAutoGenerator.preview`（复用或待创建食材/菜品、已有餐次合并提示）→用户确认→原子提交。多日/周结果保存后关闭输入页并跳一周计划；单日结果刷新当前日期。涉及页面：`AiMealInputSheet`/`AddDayFoodScreen`/`WeekPlanScreen`。涉及数据：`ingredient`/`dish`/`meal_record` 及关系表。算法边界→[20](20_健康与算法逻辑（专属）.md)，网络与降级→[21](21_AI与网络请求策略（专属）.md)。

> ⚠ 当前已知缺口：同日多餐聚合、份量贯通、做法持久化、Schema 接入、可见警告与提交原子性仍在修复；不能把当前实现描述为已完整交付。

### 2. 查看食历
**一句话** — 按日期浏览历史+未来计划餐，回顾与复盘。
**预期行为** — 删整天为软删+可撤销；复制某天=新增到目标日。
入口：首页"看全年"/色系墙色块。页面：`FoodTimelineScreen`/`DayMealCardView`。数据：读 `meal_record(_dish)`/`dish`/`ingredient_nutrition`/`pantry`；写软删/复制。关联：上游记一餐；下游推荐去重·备份。

### 3. 创建/管理菜品
**一句话** — 新建/编辑自建菜品（食材+做法+步骤+烹饪方式）。
**预期行为** — 保存后进菜品库、可被记餐/推荐选用；预设菜不可改名，需"另存为我的菜"。
入口：菜品页新建、搜索无结果新建（带名）、自由搭配"存为菜品"、食材"组成菜品"。页面：`NewDishScreen`/`IngredientPickerScreen`。数据：写 `dish`/`dish_ingredient`/`dish_cooking_method_rel`/`dish_step`。关联：下游记一餐·推荐·备份。

### 4. 食材库与库存
**一句话** — 管理食材库（预设+自建）并追踪在手库存份数。
**预期行为** — 入库默认 1 份；份数=可做几次，记/计划餐自动扣减；剩余=份数−占用。
入口：食材页、菜品编辑新建、搜索新建、购物清单入库。页面：`IngredientsScreen`/`IngredientDetailSheet`/`ShoppingListScreen`。数据：写 `ingredient`/`pantry`。关联：下游记一餐缺料·库存推荐·采购·周期规划。**已知坑→[05](05_诊断地图.md)**：同名多 id、幽灵库存（食材软删）。

### 5. AI 推荐下一餐
**一句话** — 按在手食材+忌口+最近进食，推 3 个下一餐组合。
**预期行为** — 忌口/份数是硬红线（分层末位）；无网/无 key 用纯规则兜底。
入口：首页/餐次块/推荐页。步骤：规则引擎筛安全候选+打分 → 云端 LLM 组合 → JSON 校验+规则补齐 → 选它落到记一餐。页面：`AiRecommendScreen`。风格：综合/偏熟悉/偏新鲜/偏营养（调权重）。算法内部→[20](20_健康与算法逻辑（专属）.md)。数据：只读 `pantry`/`meal_record`/`member_care`/`ingredient_nutrition`。**忌口口径**：默认不推荐、模型不得选择；候选展示保留告知性标记，若全部候选均不适宜时可降级展示，不能误写为绝对不可见。

### 6. 周期规划
**一句话** — 按人数+档案一次性生成 7~30 天菜谱计划。
**预期行为** — 保存为"计划"不落库存、不计推荐去重；一键应用批量建 `meal_record`。
入口：首页周期规划/一周计划。页面：`AiPlanScreen`/`WeekPlanScreen`（算法 `PeriodPlanner`→[20](20_健康与算法逻辑（专属）.md)）。**已知坑→[05](05_诊断地图.md)**：月计划取数曾 N+1（已修 `gatherForPlan` 批量）。

### 7. 健康档案与家庭成员
**一句话** — 为家庭各成员分别记身体数据+慢病，驱动推荐与评估。
**预期行为** — 忌口取全家启用成员并集+标"对谁"；达标按成员切换（不相加）。
入口：我的/功能设置。页面：`FamilyScreen`/`FamilyStatsScreen`。数据：`family_member`/`member_care`/`user_health_profile`。

### 8. 营养评估（今日卡）
**一句话** — 实时汇总今日热量/宏量/慢病指标，评达标与搭配。
**预期行为** — 仅对已登记病种触发慢病提示；缺数据退多样性、不下调；标"仅供参考·非医嘱"。
入口：首页今日卡。评级器/色系墙口径→[20](20_健康与算法逻辑（专属）.md)。数据：读 `meal_record_dish`/`ingredient_nutrition`/`member_care`。
