# 03 · 界面与交互

> 这册讲什么：**页面清单 + 路由 + 复用组件 + 交互规范**——界面上有什么、从哪进、能做什么。
> 服务用途：掌握全貌 ✅ ｜ 反查（界面现象定位到页面）✅
> 装什么：底部 Tab、页面条目、路由表、组件库、交互模式、主题。
> 不装什么：业务流转（→[02](02_业务流程全景.md)）、数据（→[04](04_数据层.md)）。

## 概览层：导航树

四层导航：**底部 Tab(4) → 全屏内容页 → 详情/编辑页 → 对话框/Sheet**。

| Tab | 页面 | 职责 |
|---|---|---|
| 首页 `home` | `HomeScreen` | 今日概览+营养卡+计划卡+快速入口 |
| 菜品 `dishes` | `DishesScreen` | 菜品库（分类/喜爱度筛选/搜索/字母索引） |
| 食材 `ingredients` | `IngredientsScreen` | 食材库+库存 Tab；选择器/详情为独立子页面或 Sheet |
| 我的 `mine` | `MineScreen` | 个人中心+主题+备份+各功能入口 |
| 中间 ＋ | → `AddDayFoodScreen` | 新增餐食 |

## 细节层：页面条目

每页格式：**职责** ｜ 入口 ｜ 主要操作 ｜ 关键状态。

- **`HomeScreen`（首页）** — 今日食材/餐食概览。入口：启动/Tab。操作：看今日营养、编辑日期、复制昨天、跳搜索、进食历/周计划/推荐。状态：今日饭菜、营养墙折叠。
- **`FoodTimelineScreen`（食历）** — 时间线历史+计划。入口：首页"看全年"/色系墙色块。操作：日期导航、编辑/复制餐、删整天(软删撤销)、滚动加载。状态：顶/底加载。
- **`SearchScreen`（全局搜索）** — 多源搜菜品/食材/餐。入口：首页搜索图标。操作：搜、开详情、点食材跳高亮、无结果新建(带名)。**预期行为**：滑到底自动加载更多。
- **`AddDayFoodScreen`（加餐/编辑餐）** — 按餐次加菜。入口：＋/编辑日期。操作：选菜、调餐次、AI 补菜、**保存前预览**(所有保存均先预览)。状态：保存中。
- **`NewDishScreen`（新建/编辑菜）** — 编辑菜信息。入口：新建/编辑/复制/搜索无结果/食材组成菜品(均可预填)。操作：菜名、食材(分类树/搜索)、步骤模板、照片、保存。状态：脏标记(未保存守卫)。
- **`DishDetailScreen`（菜品详情）** — 只读+入口。操作：编辑、另存为我的菜、分步烹饪、记这道菜、收藏。
- **`IngredientsScreen`（食材/库存）** — 食材库复用为一级页。操作：选/编辑/新建食材、组成菜品；库存 Tab 就地加减份数、出库、**右侧 A-Z 字母定位**。**预期行为**：库存按拼音默认排序（非"最近"）。
- **`AiRecommendScreen`（AI 推荐）** — 三档推荐(库存/随机/周期)。操作：切模式、确认菜单、生成计划、改风格。状态：来源(云/本地/离线)、加载中。
- **`AiSettingsScreen`（AI 设置）** — 配来源/模型/Key。操作：切来源、选模型、测试连接、申请指引跳浏览器。
- **`FamilyScreen`/`FamilyStatsScreen`** — 成员档案/膳食统计（全家·成员切换、今日+近7天）。
- **`FeatureSettingsScreen`（功能设置）** — 开关集中：分步执行、营养色系、热量数值、库存挂钩。
- **`WeekPlanScreen`/`ShoppingListScreen`/`FreePairingScreen`/`NutritionTableScreen`** — 一周计划视图/采购清单(勾选入库)/离线自由搭配/食材营养表(横屏)。
- **`CookModeScreen`/`CookingTimerScreen`** — 分步烹饪(大字大图翻页+计时)/独立倒计时。
- **`DietaryReferenceScreen`/`NutritionRuleReferenceScreen`/`HealthScienceReferenceScreen`/`HealthConditionReferenceScreen`/`TcmReferenceScreen`/`VitaminReferenceScreen`/`DataSourceScreen`/`UpdateLogScreen`** — “我的”下的二级只读参考页；解释口径和来源，不创建第二份事实。
- **`FeatureGuideScreen`/`PrivacyConsentDialog`/`PolicyScreen`** — 首启隐私同意门、可选功能引导和协议页；未同意隐私前不得进入首页。

> 有状态或业务页面通常由对应 ViewModel 承担；静态参考页、协议页、局部 Sheet/组件可无同名 ViewModel。AI 计划页和 AI 输入 Sheet 虽非独立 NavHost 路由，仍有独立状态与 ViewModel。

## 参考层：路由与组件

**路由**（`Destinations.kt`/`MainScaffold.kt`）：底栏 `home`/`dishes`/`ingredients`/`mine`；记录与计划 `timeline`/`timeline_full?date`/`addmeal?date&dishIds&copyFrom`/`week_plan?date`/`diet_report`；菜品 `newdish/{dishId}/{importDishId}`/`dish/{dishId}`/`cook/{dishId}`；智能 `ai_recommend?returnResult&slot`/`ai_settings`；工具与档案 `family`/`family_stats`/`feature_settings`/`shopping_list`/`free_pairing`/`nutrition_table`/`cooking_timer`；参考/合规 `dietary_reference`/`nutrition_rule_reference`/`health_science_reference`/`health_condition_reference`/`tcm_reference`/`vitamin_reference`/`data_source`/`update_log`/`user_agreement`/`privacy_policy`/`feature_guide`。

**返回与直达**：`NewDish` 通过 `createdDishId` 回填记餐；AI 推荐通过 `aiPickedDishes` 回填记餐；通知 `EXTRA_OPEN_TIMER` 可直达计时器。其余跨页预填使用下述 Koin 总线。

### AI 记一餐确认页（V2 已决交互）

`AiMealInputSheet` 的确认态是“核对并记下”，不是健康诊断页。顶部固定展示解析来源（AI / 规则解析）与结果状态；AI 异常状态后提供结果图标，点开先看失败阶段、脱敏摘要、模型/HTTP 状态和耗时，原始返回必须二次点击才临时展示，关闭即清除。

餐食按日期/餐次分组，可编辑并显示已有餐次合并、待创建实体及本机健康事实。确认态使用**整页单一滚动区**：无论餐次卡、健康提示或建议多长，“查看建议”“修改”“确认记下”都必须可滚动到且可点击，不能被 Sheet 裁切。**确认餐食区下方**放“查看建议”入口：首次点击说明本次会将去标识化最小健康摘要交给 AI，单次同意后显示建议；未同意、加载、失败和无建议均有明确状态。建议仅供参考、非医嘱，纯本次会话展示，不能复制、分享、保存或在下次进入恢复。建议的可用性和内容均不改变“确认记下”的可操作性。

**跨屏传参总线**（Koin single）：`NewDishPrefillBus`(搜索/组成菜品→新建预填)、`IngredientCreateBus`(搜索→新建食材)、`IngredientJumpBus`(跳到食材高亮)。

**复用组件库**（`ui/component/`，选列）：`AppTopBar`/`AppSearchField`/`PrimaryTabRow`/`SegmentedControl`/`InsetGroup`/`PlainCard`/`ActionSheet`/`CapsuleButton`/`MiniStepper`/`FormBottomBar`/`ToggleChip`(**v29·固定多选实心/描边胶囊·餐次+个人忌口共用·§9.21**)/`DayMealCardView`/`DishRow`/`DishMiniCard`/`IngredientCard`/`EmptyState`/`StarRating`/`StoredImage`/`FoodEmoji`/`AppSnackbar`/`UnsavedGuard`/`PantryHook`/`PinyinIndex`(字母索引+LetterIndexBar)/`NutritionColor`。选择器 `ui/picker/`：`DishPickerScreen`(**v28·可选餐次预筛**)/`IngredientPickerScreen`/`IngredientDetailSheet`/`CategoryDialogs`。
