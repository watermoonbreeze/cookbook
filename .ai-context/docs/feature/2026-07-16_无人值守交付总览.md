## 三慢病健康维度（part2 关键路径）

### 1. DIABETES GI 评级分支 `0cdd483`
- **一句话**：解锁糖尿病维度——今日卡按当天主料匹配高GI(≥70)食物给"可换低GI/控量"提示。
- **操作逻辑**：`NutritionLevelEvaluator.matchHighGiFoods(主料名, giByName)` 按名查已在库 gi≥70(FAO/WHO口径,非WS/T652)；`evaluate` 加 DIABETES 分支；`NutritionRepository.giByName()`(同名取较高值·key trim 归一)；HomeVM gate 糖尿病才查表。缺数据不下调(向后兼容)。
- **怎么验证**：登记糖尿病 → 当天记含米饭/馒头等高GI主料的餐 → 今日卡出现"含X等高GI食物·糖尿病可换低GI或控量"；不含高GI主料或没登记糖尿病则无。
- **详细**：`营养数据治理方案.md §三批次1`。

### 2. 详情页 GI/嘌呤定性提示 `15194ed`
- **一句话**：把慢病定性下沉到"选菜决策时点"——菜品详情页显示 GI/嘌呤补充提示（作为 care 忌口的 data-driven 补充）。
- **操作逻辑**：`dishQualitativeHits(主料名, 病种, giByName, 已在avoid∪limit的名)` 纯函数——gate 病种 + 复用 matchHighGi/Purine + `filterNot` 去重(care 已覆盖的食材不重复)；病种取全家 enabled 档案(与本页 avoid/limit 同源)；只算主料；措辞成分陈述(非整菜定性·规避 GL 陷阱)。
- **怎么验证**：登记糖尿病/痛风 + 打开含高GI主食/高嘌呤主料(猪肝等)的菜详情 → care 忌口行下方出现"📈 升糖:高GI:X"/"🍖 嘌呤:偏高:X"独立行；已在 care 忌口/限量的食材不重复显示。
- **多角色验证**：临床营养/产品 + 架构/UX。**详细**：`详情页GI嘌呤定性提示.md`。

### 8. 慢病数值软约束（推荐软降）`0761410`
- **一句话**：登记糖尿病/痛风家庭，推荐时把高GI/高嘌呤主料的菜梯度软降（排后不剔除，仅"偏营养"风格生效）。
- **操作逻辑**：`HealthRuleEngine.evaluate` 加因子 `chronicDiseaseNutrition`(默认0·仅NUTRITION风格=0.6)；penalty=`(min(highGi,2)+min(highPurine,2))×0.25` 封顶0.7 → 营养风格实际最大软降≈0.42(<核心信号,不越分层)；复用 dishQualitativeHits 去重；**钠不做**(菜级sodiumMg含调料无法拆·每道菜都放盐会误伤全部,钠靠 care limit+做法提示+今日卡)；不改 sortedWith 分层(忌口仍绝对末层)。
- **怎么验证**：登记糖尿病+AI推荐选**"偏营养"**风格 → 含米饭/馒头等高GI主料的菜比同类普通菜靠后(仍在列表·不标红·不剔除)；切**"综合"**风格则无此效果(默认0)；忌口菜始终最末。
- **多角色验证**：临床营养/算法 + 产品/免责（4角色）。**详细**：`慢病数值软约束.md`。

> DIABETES GI 分支的今日卡侧与详情页/软降协同：三慢病定性现覆盖 **今日卡(聚合·关注成员) + 详情页(单菜·全家档案) + 推荐软降(排序·营养风格)**；高血压(P1钠)/痛风(P4嘌呤)/糖尿病(P2 GI)均进评级器各有单测。

### 9. FoodGroup.classify 跨类冲突 & 脏输入单测 `a9b9ea9`（本项·纯测试硬化·无单独 feature 文档，内容如下）
- **一句话**：给脆弱的启发式食材分类(classify)补 10 个单测，锁住历史红线跨类冲突，防后续改关键词表回退。
- **背景**：`FoodGroup.classify(食材名)` 是"尾词优先 + 特例表 + 判定顺序"的 by-name 启发式，历史多次踩坑(脱脂牛奶含"牛"判红肉、鸡毛菜含"鸡"判禽、鱼豆腐含"鱼"判水产)。现有测试只覆盖 nutritionLevel、**零 classify 覆盖**。
- **操作逻辑（锁住的判定顺序）**：①NAME_OVERRIDE 特例表最优先 → ②endsWith("油")→null、endsWith("腐")→豆坚果 → ③尾词 蛋/奶/肉(肉含鸡鸭鹅→禽否则红肉) → ④含"血"→红肉 → ⑤菌藻关键词(菇/木耳/海带/紫菜)→菌藻 → ⑥endsWith 菜/苗→蔬菜 → ⑦关键词优先级(蛋→奶→水产→禽→红肉→主食→豆→**水果先于蔬菜**→蔬菜)。
- **锁住的红线用例**：脱脂纯牛奶→奶(非红肉)、鸡毛菜→蔬菜(非禽)、咸鸭蛋→蛋、兔肉→红肉、鸭血/猪血→红肉、紫菜/海带/黑木耳/猴头菇→菌藻、鱼豆腐/臭豆腐→豆坚果、花生油→null(油菜仍蔬菜)、木瓜/西瓜→水果而冬瓜/南瓜→蔬菜、西红柿/凉皮/柠檬/肥肠(特例表)、脏输入(空/空白/料理包/沙拉酱/符号/数字)→null 不崩、groupsOf 去重保序 + explicit 优先。
- **怎么验证**：跑 `scripts\build-cli.bat :shared:testDebugUnitTest`，`FoodGroupClassifyTest` 全绿即锁成功；后续谁改 `FoodGroup.KW` 关键词表若破坏上述归类，该测试会红。
- **纯测试、零生产改动**（全部断言通过=匹配现有正确行为；按门禁"小改可免"未 spawn Google 审查）。文件：`shared/src/androidUnitTest/.../FoodGroupClassifyTest.kt`。
