> 裁决日期：2026-08-29；授权：用户要求 SOL 将所有待定方案定掉。

## 一、总顺序

`D1 推荐可复现性` → `D2 解析规范化语料` → `D3 调味料透明文案` → `D4 显式本地偏好` → `D5 无障碍基础` → `D6 餐状态 ADR/迁移` → `R10 真机`。

其中 D1–D5 互不改 schema、健康阈值或云端协议，可各自独立建 L7；D6 必须先完成 ADR、依赖图、迁移/回滚演练后才允许任何数据变更。R10 不等待二期或 AI 扩展。
