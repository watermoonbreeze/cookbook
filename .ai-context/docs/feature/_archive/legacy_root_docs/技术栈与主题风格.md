### 项目架构

采用标准 KMP 项目结构，UI 与共享逻辑分离。Android 端 **2026-05-19 确定使用纯 Compose**（不混合 Fragment）。

- **`:shared`** — 跨平台共享模块，包含 `commonMain`、`androidMain`、`iosMain` 源集。存放 Data 层（Repository、SQLDelight）和 Domain 层（Model、UseCase）。iOS 端编译为静态 framework（`baseName = "shared"`）。
- **`:androidApp`** — Android 应用模块，依赖 `:shared`，**单 MainActivity + Compose NavHost** 架构，所有页面是 Composable Screen。
- **`iosApp/`** — iOS 应用工程（Xcode），使用 SwiftUI 构建 UI 层，**MVP 不实现**（仅保证 shared 可编译出 framework），一期再做。

### 目标平台

| 平台 | 优先级 | 说明 |
|------|--------|------|
| Android | P0 | 主要使用平台，纯 Jetpack Compose + Material3 |
| iOS | P1 | **MVP 不开发**，shared 能编译 framework 即可；一期 SwiftUI 落地 |

### MVP 阶段原则

- 纯本地存储，不涉及网络和后端
- 单 Activity + 纯 Compose 架构，所有 5 个 Tab 是 Composable
- `shared` 模块存放所有跨平台业务逻辑，`androidApp` 仅负责 UI
- DishesScreen / DayMealCardView 等关键组件按"复用"原则设计（参数化模式 / 跨页直接调用）

## 二、主题风格

采用 **Material Design 3 (Material You)** 设计规范。

### 2.1 配色方案

整体定调：**绿色为主色 + 蜂蜜橙作暖色辅助**。绿色传达健康/自然，暖橙降低医院/养生风的冷感，让中老年用户也觉得亲和。

基于 Material 3 Dynamic Color 体系，定义 Light / Dark 两套主题。

#### 语义色板（Extended Colors，独立于 Material 标准 ColorScheme）

为了支撑后续健康维度提示（人群风险、嘌呤/糖/脂分级等），单独预留三档语义色，**不复用** Primary/Tertiary/Error，避免业务语义与品牌色耦合：

```
Light Theme:
  Success (健康/低风险/推荐):
    Color:          #2E7D32
    OnColor:        #FFFFFF
    Container:      #C8E6C9
    OnContainer:    #0E3812

  Warning (中风险/慎食/提醒):
    Color:          #ED6C02
    OnColor:        #FFFFFF
    Container:      #FFE0B2
    OnContainer:    #3A1F00

  Danger (高风险/禁忌/超标):
    Color:          #C62828
    OnColor:        #FFFFFF
    Container:      #FFCDD2
    OnContainer:    #410005

Dark Theme:
  Success:
    Color:          #A5D6A7
    OnColor:        #0F3713
    Container:      #1B5E20
    OnContainer:    #C8E6C9

  Warning:
    Color:          #FFB74D
    OnColor:        #3A1F00
    Container:      #7A4A00
    OnContainer:    #FFE0B2

  Danger:
    Color:          #EF9A9A
    OnColor:        #410005
    Container:      #B71C1C
    OnContainer:    #FFCDD2
```

**使用约定**：
- `Tertiary` 暖橙 = **品牌强调**（收藏组合、复用、暖意装饰），与"警告"无关
- `Warning` 暖橙 = **业务警告**（中风险提示徽标），色值更亮更显眼，跟 Tertiary 做出区分
- `Error` 红 = 系统级错误（输入错误、删除确认）；`Danger` 红 = 健康业务级禁忌提示

> 实现方式：在 `androidApp` 定义 `data class ExtendedColors(...)` 通过 `CompositionLocalProvider` 注入，使用时 `LocalExtendedColors.current.warning`。iOS 端 SwiftUI 通过 `Color` 扩展实现同样语义。

> 具体色值可通过 [Material Theme Builder](https://m3.material.io/theme-builder) 微调；语义色独立维护。

### 2.2 字体排版

遵循 Material 3 Type Scale：

| 用途 | Style | 场景 |
|------|-------|------|
| 页面标题 | TitleLarge (22sp) | 首页标题、页面顶部 |
| 卡片标题 | TitleMedium (16sp) | 餐次标题（早餐/午餐/晚餐） |
| 正文内容 | BodyLarge (16sp) | 菜品名称 |
| 辅助文字 | BodyMedium (14sp) | 日期、分类标签 |
| 标签文字 | LabelMedium (12sp) | Chip 内文字、提示信息 |

### 2.3 核心组件风格

| 组件 | Material 3 组件 | 用途 |
|------|-----------------|------|
| 顶部栏 | TopAppBar (SmallTopAppBar) | 页面标题与导航 |
| 卡片 | ElevatedCard / OutlinedCard | 每餐记录卡片 |
| 标签 | AssistChip / InputChip | 菜品标签，支持删除 |
| 按钮 | FilledButton / TextButton | 添加、复用等操作 |
| 弹窗 | ModalBottomSheet | 添加菜品弹窗 |
| 搜索 | SearchBar | 菜品搜索 |
| 日历 | 自定义 (基于 LazyRow) | 周视图日期选择 |
| 浮动按钮 | FloatingActionButton | 快速添加入口（可选） |

### 2.4 圆角与间距

- 卡片圆角：12dp (Material 3 Medium)
- Chip 圆角：8dp (Material 3 Small)
- 底部弹窗顶部圆角：28dp (Material 3 ExtraLarge)
- 内容间距：16dp（页面边距）、8dp（元素间距）

### 2.5 动效

- 页面切换：Material 3 SharedAxisTransition（水平方向）
- 底部弹窗：标准上滑弹出
- 列表项：淡入动画
- 交互反馈：Material 3 Ripple

### 2.6 主题切换

MVP 阶段 **Light / Dark 双主题同步上线**，提供用户手动切换能力：

- **三档可选**：跟随系统 / 浅色 / 深色（默认"跟随系统"）
- **持久化**：用户选择写入本地（`DataStore` 或 SQLDelight 键值），冷启动后保留
- **切换入口**：
  - 主入口：MineScreen "外观 → 主题切换" → 三选一
  - 快捷入口：HomeScreen 顶部右上角 ☀/🌙 图标（Tertiary 橙），点击轮换三档
- **跨平台**：Android 端通过 `MaterialTheme(colorScheme = ...)` 切换；iOS 端 SwiftUI 通过 `colorScheme` 环境变量绑定，业务层共享主题状态（`shared` 模块的 `ThemeRepository`）
- **Extended Colors 同步切换**：语义色板的 Light/Dark 版本由 `CompositionLocalProvider` 在主题切换时一并注入
