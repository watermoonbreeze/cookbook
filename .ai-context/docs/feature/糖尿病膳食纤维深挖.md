# 糖尿病膳食纤维深挖（高纤延缓升糖）

> 2026-07-17 无人值守。逐病种深挖第 2 病种（北极星 part2·§八.1 "高血压端到端跑通后复制到糖尿病"）。
> **完全比照高血压钾正向维度**（同一保守模式）。多角色验证（权威指南研究员联网核准 + 钾先例 PM 口径 + Google 审查）。

## 一句话
糖尿病评级此前只罚高 GI（≥70 主料→"可换低GI/控量"），不看膳食纤维。本版补**纤维正向提示**——高纤延缓葡萄糖吸收、削平餐后血糖峰（指南方向性推荐），让糖尿病家庭"吃够纤维也被认可"，与钾之于高血压同构。

## 操作逻辑（公式/阈值/数据来源/何时生效）
- **数据来源与阈值（权威可回溯）**：
  - 膳食纤维每日锚 **DRIs 2023 成人 AI = 25~30 g/日**（WS/T 578 系列，2023 版首设 AI），膳食指南2022 同值；糖尿病同为 25~30 g/日（或 ≥14 g/1000kcal，中国2型糖尿病指南2020/ADA），**无更高专属硬阈值**。GB 28050-2011 高纤维声称 ≥6 g/100g（食物级）。
  - 机制：可溶性纤维成黏性凝胶延缓葡萄糖吸收、削平餐后血糖峰（**ADA B 级证据·方向性推荐，非可定量换算**）。
  - `FIBER_DAILY_G = 25.0`（取 AI 下界，保守）、`FIBER_ADEQUATE_RATIO = 0.8`（≈20g；国人均摄入仅~15g，达此为高纤日）。
- **判定（`NutritionLevelEvaluator.evaluate` 末尾分支，纯函数可单测）**：仅**已登记糖尿病** 且 `totals.fiberG > 0` 时：`fiberRatio = fiberG / (25 × dayCount)`；`≥ 0.8` → 追加正向 concern「膳食纤维较充足（约X%建议量）· 利于餐后血糖平稳 · 仅供参考」。放末尾→正向排在负向（高GI）之后。
- **红线（完全同钾，采纳权威研究员保守口径）**：
  - 纤维**不改级别**（只 `concerns +=`）。
  - **不抵消 GI 罚分**——"纤维抵消 GI"**无权威换算依据**（同"钠钾比无国标阈值"结论）；且 GI 按主料成品测定已部分含纤维基质效应，再叠加会双重计算。高GI+高纤时"可换低GI"与"纤维充足"两条**正交并存**。
  - **低纤绝不下调**——低纤扣分越免责红线，且纤维覆盖仅 65%、缺数据会大面积误判；无数据→静默不触发（向后兼容）。
  - 措辞守免责：用"较充足/利于/仅供参考"，禁"降糖/治疗/达标"。
- **接线**：`HomeViewModel.personalTotals` 补 `fiberG = totals.fiberG * share`（按关注成员份额，与钠/钾一致）。零迁移（`NutritionTotals.fiberG` 全链路已通、fiber 覆盖 65%）。
- **GI/GL/碳水计数不做**（研究员判断：过于临床、易被当医嘱误导剂量）；维持现有 GI 主料评级。

## 用户验证方法（真机/数据怎么判断对不对）
前置：家庭档案给关注成员勾选"糖尿病"；当天记的菜含高纤食材（全谷/杂豆/绿叶/薯类）。
1. **高纤日**：记满高纤且无高GI主食的一天 → 今日卡出现「膳食纤维较充足（约X%建议量）· 利于餐后血糖平稳 · 仅供参考」，**级别不因纤维变化**。
2. **高GI+高纤**：又吃白米饭又高纤 → 同时出现「含白米饭等高GI食物·可换低GI或控量」**和**「膳食纤维较充足…」两条，**高GI在前**、级别仍被 GI 封（纤维不抵消）。
3. **低纤**：纤维不足的一天 → **无**纤维提示，级别与改动前一致。
4. **向后兼容**：无纤维数据的菜 / 未登记糖尿病 → **看不到**纤维提示。
5. **自动化**：`:shared:testDebugUnitTest` 的 `NutritionLevelEvaluatorTest` 新增 4 用例（纤维充足正向不改级别 / 高GI高纤并存不抵消 / 低纤不提示不下调 / 无数据·未登记 gate）全绿即锁。
