## 目标

- 内测期间优先使用本地日志，不上传服务端，日志目录为 `/sdcard/cookbook/log/`。[AI生成]
- 日志按日期生成：`yyyy-MM-dd.log`，方便导出最近几天给 Codex 分析。[AI生成]
- 埋点只记录流程、ID、数量、耗时和状态，不记录图片路径、备注全文、用户隐私文本。[AI生成]

## 日志类型

- `MealFlow`：添加/编辑餐食链路，排查餐次、菜品回填、保存和日期加载。[AI生成]
- `DishPickerFlow`：菜品选择弹框链路，排查刷新、选择、跳新建、确认。[AI生成]
- `NewDishEdit`：新建/编辑菜品链路，排查编辑参数、加载、保存回传。[AI生成]
- `AppEvent`：内测埋点事件，用 `AppLogger.event(name, params)` 记录。[AI生成]
- `AppCrash`：未捕获异常摘要，发生闪退时同步写入日志文件。[AI生成]

## 参数规范

- 使用 ID 和数量，不写用户输入全文。[AI生成]
- 菜名、食材名只在排查明确需要时临时加入；常规埋点不采集。[AI生成]
- 图片只记录数量和成功/失败，不记录完整文件路径。[AI生成]
- 错误只记录 `errorType` 和简短 message，不记录大段堆栈；崩溃堆栈后续可单独做 crash 日志。[AI生成]
