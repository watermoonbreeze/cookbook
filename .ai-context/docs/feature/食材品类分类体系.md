# 食材品类分类体系（配置就绪 · 定稿）

> [AI生成] 2026-07-06。参考：《中国居民膳食指南(2022)》五大类框架、生物学科属细分、项目 `日常食材维度.md`。
> 用途：作为 `food_category` 品类树的 seed 配置。只列分类、不含具体食材。
> 定位：单一"品类"维度（食材是什么），家庭直觉优先。营养/GI/慢病等不在此树，作 food_category 其它 dimension，见 `食材维度体系设计.md`。

## 设计规范

- **层级封顶 3 层**：大类(L1) → 中类(L2) → 小类(L3)；多数食材归到 L2 即可，L3 仅在必要时细分。
- **单一维度**：只按"食材本身是什么"分，不混营养/功能/人群维度。
- **配置形式**：每个节点 = 一条 `food_category` 记录（id/name/parent_id/emoji/sort_order）。下方缩进即父子关系。
- **MECE**：同层不重叠、合并可穷尽；有争议食材归到最主要用途的品类。
- **自定义**：用户自建食材/分类靠 `source=user` 区分（视图），不在本品类树里占节点。

## 说明与可选调整

- 已按膳食指南五大类扩展为 13 大类，覆盖谷薯/蔬/菌藻/果/畜禽/水产/蛋/奶/豆坚果/油脂/调味/方便食品/其他。
- **蛋、奶保持独立大类**（膳食指南规范），未合并为"蛋奶"；如你更想合并可提。
- 层级：多数到 L2（中类），肉/鱼/瓜茄到 L3（小类）。
- 归类争议按主要用途归一处：杂豆→主食（当饭吃）、大豆→豆坚果（蛋白源）、干果→水果、坚果→豆坚果。
