# AI 推荐页 · 界面精简重设计方案

> [AI生成] 2026-07-19 apple_ux_designer 起草。用户诉求："AI 推荐界面除了三个分类，其他子选项太长了，统一精简，功能不缺失前提下优化操作逻辑和 UI。"
> 决策点见 §五（D1–D6），待用户确认后进 Apple-UX 门禁细化 dp 再编码，沉淀回 `苹果风格UI设计方案.md §9.24`。

## 一、现状盘点（顶部控件区 ≈264dp·药膳开启 ≈304dp）
`RecommendControls`（`AiRecommendScreen.kt` L336–409）在结果列表首 item，5 段"小标题+分段控件"：
| 段 | 控件 | 组件 | 选项 | 频率 | 占用 |
|---|---|---|---|---|---|
| 0 | **推荐模式**（"三个分类"） | SegmentedControl | 库存/随机/周期计划 | 高·锚点 | ~44dp（固定层） |
| 1 | 餐次 | PrimaryTabRow 横滚 | 6（全部/早/中/加餐/晚/宵夜） | 中 | ~70dp |
| 2 | 去重周期 | SegmentedControl | 一/二/三/四周 | **低** | ~64dp |
| 3 | 推荐风格 | SegmentedControl | 综合/偏熟悉/偏新鲜/偏营养 | 低偏中 | ~66dp |
| 4 | 食养(药膳) | SegmentedControl | 不限/药食同源 | **很低** | ~64dp |

问题：进页面先撞五段控件吃掉半屏；**"三个分类"=推荐模式(留)**；**"子选项太长"=餐次+去重周期+风格+药膳四段全展开**+每段带长说明句噪音；低频项(去重/药膳)与高频餐次平级常驻，违"默认只露高频"。

## 二、精简方案 A（推荐）
**推荐模式留固定层不动 → 餐次下沉常驻二级横滚栏(§9.21) → 去重周期/风格/药膳三个低频项收进一个「筛选」ModalBottomSheet(§9.16/§9.8)**。
```
[ 库存推荐  随机推荐  周期计划 ]        ← ① 模式(固定层·不动)
全部 早餐 中餐 加餐 晚餐 宵夜  →         ← ② 餐次二级横滚栏(常驻·§9.21)
已为你推荐 10 道        ⚙筛选· ↻换一换   ← ③ 结果头行(筛选带小圆点=有非默认筛选生效)
▢ 番茄炒蛋  ⭐你常做…                     ← 结果列表(模式/餐次吸顶)
   [ 加入这一餐(已选2道) ]              ← 底部胶囊主CTA(不变)

点⚙筛选 → ModalBottomSheet:
  推荐风格 [综合 偏熟悉 偏新鲜 偏营养] + 一行说明
  去重周期(近期吃过的排最后) [一周 二周 三周 四周]
  食养(药食同源优先·传统分类仅供参考) [不限 药食同源]
  [重置为默认](次要)
  ——切换即时生效(复用现 setStyle/setRecentWindow/setMedicinalFilter)、无"确定"
```
**收益**：默认屏控件从 ~264dp 砍到 ~90dp(模式44+餐次46)；低频三项一行入口；餐次高频仍一眼可切；切换即时。**功能零丢失**。
**代价**：改风格/去重/药膳多一次"点筛选开 Sheet"（这三项本低频·可接受）。

备选 B（餐次也进筛选·最省屏但违 §9.21 餐次常驻决策·不推荐）；C（仅平铺瘦身·治标不治本·保底）。

## 三、操作逻辑优化
- **筛选态可见性**：有任一非默认筛选(风格≠综合/去重≠一周/药膳开)时筛选图标加小圆点(§9.11)，防"收纳后忘了设过"。
- 切换即时无"确定"；粘性态全保留(recommendStyle 持久化 + slot/window/medicinal 粘性)；长小标题瘦身(标题+右侧灰字副说明)；风格动态整句说明移进 Sheet。
- 换一换保持结果头行右侧常驻，与筛选并列。

## 四、复用组件（零新造·唯一新增 RecommendFilterSheet 私有 Composable 组合已有件）
SegmentedControl / PrimaryTabRow / AppTopBar / CapsuleButton / ResultHeader(微调) / ModalBottomSheet / Divider(非 HorizontalDivider·M3 1.1.2) / §9.11 小圆标。改动点：`AiRecommendScreen.kt`(RecommendControls 拆分)、`AiRecommendViewModel.kt`(逻辑不改·仅可选加"筛选是否非默认"派生标志)。

## 五、决策点（每点给推荐）
- **D1 餐次放哪**：二级横滚栏常驻(推荐·§9.21) / 进筛选 Sheet(违常驻决策)。→ **二级栏**
- **D2 风格/去重/药膳收进筛选 Sheet**：三者全收(推荐) / 只收去重+药膳留风格。→ **三者全收**
- **D3 筛选入口容器**：ModalBottomSheet(推荐·富内容分段控件) / ActionSheet(仅适纯动作列表)。→ **ModalBottomSheet**
- **D4 餐次按钟点智能预选**：暂不改·保持"全部"(推荐·全量页留全部更稳·智能预选留首页轻量卡) / 进页面按当前时段预选。→ **暂不改**
- **D5 筛选生效提示**：小圆点(推荐·克制) / 文字"筛选·2"。→ **小圆点**
- **D6 "重置为默认"**：保留但低调(推荐) / 砍。→ **保留**

## 六、兼容并行改动
- 餐次 6 档：二级栏横滚天然适配（其中"加餐"为菜品页统称 chip=含上午/下午/加餐，见菜品页餐次统称改动，仅菜品分类用）。
- 换一批：结果头行右侧，与筛选并列。
- 首页轻量推荐卡(阶段2)：重控件(模式/餐次/筛选)留 AI 全量页，首页不放——本方案强化"全量页承载重控件、首页只预览"分工。
