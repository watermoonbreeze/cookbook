## 四、根因分析

### 🐛 Bug 1（阻断）：吃/喝动词未被剥离

**文件**：`shared/src/commonMain/kotlin/com/sxdbsm/cookbook/ai/meallog/RuleMealParser.kt`
**位置**：`parseMealBlock()` 方法，`removeMealKeywordPrefix()` 之后

`removeMealKeywordPrefix()` 只去掉餐次词（中午/早上/晚上），不去掉紧跟在后面的吃/喝动词。`"吃了红烧肉和米饭"` 中的 `"吃了"` 被保留，最终成为菜名的一部分 + 被提取为食材。

**涉及的关键词**（需新增剥离）：吃了、吃了些、吃了点、刚吃了、刚才吃了、喝了、喝、吃

### 🐛 Bug 2（阻断）：单字分隔词 `"和"` / `"跟"` 被 `couldBeDish` 误杀

**文件**：同上，`splitSoft()` 方法

`Regex.split` 带捕获组时返回 `[菜1, 分隔词, 菜2]`。原代码对**全部元素**调 `couldBeDish`：
```kotlin
parts.all { couldBeDish(it) }  // "和" 长度=1 → false → 整段不拆
```
应该只检查偶数索引的菜名，跳过奇数索引的分隔词。

**影响的分隔词**：`"和"`(1字), `"跟"`(1字), `"搭"`(1字) — 凡是长度为1的分隔词都受影响。
**不受影响的分隔词**：`"还有"`(2字), `"以及"`(2字), `"另外"`(2字) 等 ≥2 字的。

### 🐛 Bug 3（建议）：语音识别实例不匹配

**文件**：`androidApp/src/main/java/com/sxdbsm/cookbook/android/ui/ai/AiMealInputSheet.kt`
**位置**：`InputPhase()` composable 的 `onPress` 回调 + `startVoiceRecognition()` 函数

`startVoiceRecognition()` 内部 `new VoiceRecognizer()` 建实例A并 startListening，但松手时 `voiceRecognizer.stopListening()` 调用的是 `remember` 的实例B（从未被 start）。实例A 永不收到 stopListening → 识别挂起/超时。

## 五、修复方案

### 修复 1：RuleMealParser — 剥离吃/喝动词

在 `parseMealBlock()` 中，`removeMealKeywordPrefix()` 之后加一行：
```kotlin
cleanText = removeEatingVerbs(cleanText)
```

新增常量和方法：
```kotlin
/** 句首吃/喝动词（按长度降序，startsWith 匹配）。[AI修改] */
private val EATING_VERB_PREFIXES = listOf(
    "刚才吃了些", "刚吃了些", "刚才吃了点", "刚吃了点",
    "刚才吃了", "刚吃了", "刚吃", "吃了些", "吃了点",
    "吃了", "喝了", "喝", "吃",
)

private fun removeEatingVerbs(text: String): String {
    for (verb in EATING_VERB_PREFIXES) {
        if (text.startsWith(verb)) {
            return text.removePrefix(verb).trimStart(' ', ':', '：', '-', '—', '~')
        }
    }
    return text
}
```

**安全保证**：只做 `startsWith` 前缀匹配，不影响菜名中间的"吃"字。

### 修复 2：RuleMealParser — 修复 splitSoft 分隔词检查

```kotlin
private fun splitSoft(text: String): List<String> {
    val parts = SOFT_SPLIT.split(text).map { it.trim() }.filter { it.isNotBlank() }
    if (parts.size >= 3) {
        // 只取偶数索引 = 实际菜名（奇数索引是分隔词本身）
        val dishNames = parts.filterIndexed { i, _ -> i % 2 == 0 }
        if (dishNames.all { couldBeDish(it) }) return dishNames
    }
    return emptyList()
}
```
