## 1. Reality Verification / 根因

1. `HomeViewModel.focusSwitcher` 只合并 `observeMembers()` 与 `observeViewingMember()`，未输入当天 `observeAbsenteeIds(date)`；它把所有关注成员直接发布为 Tab。
2. `todayNutrition` 依赖 `observeFocusShareForDate(today)`；当查看成员已缺席，份额为 `0.0`，该流明确返回 `null`，而 `HomeScreen` 仅在 `todayNutrition != null` 时渲染 `NutritionTodayCard`，故包括 Tab 在内整张卡消失。
3. 根因是首页为“今日”选择成员时没有使用“在场关注成员”投影，而非缺席持久化或营养计算错误。
4. 当前无涵盖此投影的 `BusinessTrace` / `StructuredLogEvent`；本批只记录匿名的投影结果状态，不记录成员 id、姓名、日期或营养值。
