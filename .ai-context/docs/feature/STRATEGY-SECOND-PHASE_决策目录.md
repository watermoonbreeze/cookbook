## 2. 决策包统一模板

每个 ADR 至少包含：问题与非目标、三种可比较选项、目标用户证据、成本/隐私/版权/健康影响、最小试验、成功与止损指标、回滚方案、责任人和生效日期。没有这些字段的“想法”不得进入代码队列。

## 3. 与执行路线的关系

- R1–R8 的确定性质量、数据和体验改进可独立完成；不得以二期目标改变其已冻结的产品契约。
- 任一 ADR 被明确采用后，先新增该 ADR 对应的 R9-x 研究批，再通过独立 L7 蓝图进入代码；禁止直接从本目录跳到实现。
- 本目录中的事项不进入 R10 的功能通过率分母；只有未来已经实施的批次才新增设备验收项。
