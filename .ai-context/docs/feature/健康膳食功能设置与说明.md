## 四、计算规则与参考值（原理，全部写清；也用于 in-app 说明）

### 4.1 基础代谢 BMR（Mifflin-St Jeor 公式）
- 男：`10×体重kg + 6.25×身高cm − 5×年龄 + 5`
- 女：`10×体重kg + 6.25×身高cm − 5×年龄 − 161`
- 例：男 70kg/175cm/30岁 → BMR=1648.75 kcal。
- 原理：静息状态维持生命所需最低热量。参考：Mifflin-St Jeor（公开通用公式）。

### 4.2 每日消耗 TDEE = BMR × 活动系数
| 活动水平 | 系数 | 说明 |
|---------|------|------|
| 久坐 | 1.2 | 几乎不运动、办公室 |
| 轻度 | 1.375 | 每周轻运动 1-3 天 |
| 中度 | 1.55 | 每周中等运动 3-5 天 |
| 高度 | 1.725 | 每周高强度 6-7 天 |
- 例：上例中度 → 1648.75×1.55 ≈ **2556 kcal/天**，即每日目标热量。

### 4.3 达标评定（当日摄入 vs 目标）
- 达标区间 = 目标 **±15%**。
- < 目标×0.85 → **偏低**；在区间内 → **达标**；> 目标×1.15 → **超标**。
- 例：目标 2000 → 1700~2300 达标，<1700 偏低，>2300 超标。

### 4.4 个人摄入估算（核心：全家餐 → 每个人）★
- 记菜仍是**全家一份**（不改流程）。每人某餐热量是**派生估算、不单独存**：

  `个人某餐热量 = 该餐全家总热量 × (自己系数 ÷ 在场成员系数之和)`

- 例：一餐全家 2400 kcal，在场爸1.2+妈1.0+娃0.5=2.7 →
  爸≈1067、妈≈889、娃≈444 kcal。
- **准确度三档**：
  1. 默认（零操作）：每餐全员在场按系数分摊。
  2. 可选微调：某餐标「谁没吃」，从该餐分母剔除（在外吃/出差）。
  3. P3 精确（可选）：某餐某菜标「谁吃了/几份」。留给较真用户，非默认。
- **局限（必须标注）**：系数法假设「每人按同比例吃了每道菜」，算不出「娃不吃辣、爸专挑肉」。故数字一律写「**约/估算**」+ 免责，不呈现为精确摄入。

### 4.5 营养色系等级（餐食卡片/色系墙配色口径）
按当天主料覆盖的「三大类」——蛋白（鱼/红肉/白肉/蛋/奶/豆）、主食、蔬果（菜/菌/果）：
| 级别 | 判定 | 文字 |
|------|------|------|
| 0 | 无记录 | （空） |
| 1 | 仅 1 类 | 较单一 |
| 2 | 2 类 | 尚可 |
| 3 | 三大类齐 | 均衡 |
| 4 | 三类齐且食材≥5 大类 | 营养优 |
- 越均衡越偏健康绿、越单一越偏暖色。

### 4.6 三大宏量供能均衡（推荐/互补参考）
目标供能占比（参考中国居民膳食指南整理）：蛋白 ~20%、脂肪 ~28%、碳水 ~52%。近期偏离越大，推荐越倾向补足缺口的菜。

### 4.7 忌口 / 病种适宜（家庭并集）
- 忌口取**全家启用成员的并集**：某菜对任一成员忌口即标红/降权，并**标注对谁**（"五花肉·爸爸忌口"）。
- 只作用于**非调料**食材；调料的忌口/限量转「少盐/少糖」做法提示，不整菜剔除。
- 原理：做一道菜要同时避开所有人的忌口——并集是做菜决策的天然口径。

### 4.8 单位→克换算（营养计算基础）
`克数 = 用量 × 单位克当量`（克=1、两=50…）；计件单位（个/勺/片）用食材「单件克重」折算，缺失则用兜底克重并标「估算」。每 100g 营养 × (克数/100) 累加成菜/餐/日。

### 4.9 数据来源与免责
食材营养/详情为 AI 参考整理、非权威核对（`review=pending`），来源填 `ref`。所有热量/达标/忌口均为**参考估算、非医嘱**，界面须带免责。
