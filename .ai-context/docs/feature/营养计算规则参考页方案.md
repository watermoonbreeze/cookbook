## 二、🔴 红线（务必守）

1. **展示 ≠ 判定数据源**：本页是**给人看的静态文案**（硬编码在 `NutritionRuleReference.kt`，仿 `DietaryReference.kt`），**判定引擎不 import/不反读本页**；本页也**不 import 判定常量**当数据源。两份独立。**但初始数值必须与判定常量一致**（人工核对搬运，源头是 shared 各判定常量）。
2. **每个阈值标口径来源**：国标 / FAO-WHO / 惯例非国标 / 指南年份，逐条标。
3. **健康免责**：顶部免责 banner + 底部重申「仅供参考·非医嘱」；嘌呤三级必标「惯例非国标」；GI 标「FAO/WHO 口径」；热量守「个人概念·仅供参考」。
4. **不制造焦虑**：白话讲清，不点病名吓唬，正向指标（钾/纤维）说明「只加提示不改评级」。

## 三、页面结构（自定义 InsetGroup 式·仿 HealthConditionReferenceScreen）

命名建议：路由 `nutrition_rule_reference`；页面标题「营养怎么算的」或「营养计算说明」（**最终 label 由 copywriter 定**）。

**顶部**：AppTopBar + 导读 Body + 免责 banner。

**分组（InsetGroup，每组内 Para/Ref 文本）：**

### 1. 热量怎么算（🔗 HealthMetrics.kt）
- BMR（基础代谢）用 **Mifflin-St Jeor 公式**：男 `10×体重+6.25×身高-5×年龄+5`，女 `…-161`。
- 一天消耗 TDEE = BMR × **活动系数**（久坐 1.2 / 轻度 1.375 / 中度 1.55 / 高度 1.725）。
- 达标区间：目标 **±15%** 算「合适」。
- 口径/边界：**仅 18 岁以上成人**评热量（儿童青少年不评）；**孕期/哺乳期不评**（需另行专业指导）。
- 权威并列：国标 **WS/T 578.1-2017《中国居民膳食营养素参考摄入量》** 的 EER（按性别×年龄段×活动水平查表）作参照。
- 免责：热量是个人概念，需身体数据，**仅供参考、非医嘱**。

### 2. 宏量营养怎么看（🔗 Nutrition.kt）
- 供能比目标：**蛋白 20% / 脂肪 28% / 碳水 52%**（参考**中国居民膳食指南**整理）。
- 说明：用于「营养互补」提示（看最近吃的偏了哪类，推荐时补一补），**不是硬性达标线**。

### 3. 吃了多少怎么折算（🔗 IntakeCalculator.kt）
- 个人摄入 = **整份营养 × 这餐吃掉的比例 × 你分到的份额**（三者相乘）。
- 「吃掉比例」= 记一餐时选的吃完/大部分/一半/少量（默认吃完=1.0）。
- 「份额」= 家里几人分、你的饭量系数（小孩 0.5 / 成年女 1.0 / 成年男 1.2 / 老人 0.8·可在家庭档案调）。
- 说明：这是把「整桌菜」摊到「你个人」的算法，家庭分食用。

### 4. 各项分级阈值（🔗 NutritionLevel.kt / NutrientBands）
每条：指标 · 阈值 · 来源标注。**「注意/留意」两档占比口径统一**（≥100% 更注意、≥70% 留意）。
- **钠**：一般 ≤2000mg/日（膳食指南2022·NRV）；高血压 ≤2400mg/日（高血压指南2018）。
- **GI（升糖）**：低 ≤55 / 中 / 高 ≥70（**FAO/WHO 口径**；WS/T 652 只定测法、无分级）。**只按主料名判定高 GI，不给整菜 GI 数值**（避免误导）。
- **嘌呤**：低 ≤25 / 中 / 高 ≥150 mg/100g（**惯例非国标**；WS/T 560-2017 只给「应避免/限制/可选择」定性清单，无临界值）。**按主料名定性匹配**。
- **饱和脂肪**：≤20g/日（血脂指南2023·约 2000kcal 的 <10% 供能）。
- **胆固醇**：一般 <300mg/日；高胆固醇血症 <200mg/日（血脂指南2023）。
- **钾**（正向）：3600mg/日（DRIs·WS/T 578.2-2018）——**只加正向提示，不抵消钠罚分、不改评级**。
- **膳食纤维**（正向）：25g/日（DRIs2023）——**只加正向提示，不抵消 GI、不改评级**。

### 5. 膳食均衡（色系墙）怎么评（🔗 FoodGroup.kt）
- 一餐/一天的「均衡度」0–4 级：0 空 / 1 单一 / 2 尚可 / 3 均衡（三支柱齐）/ 4 优（三支柱齐且 ≥5 大类）。
- **三支柱** = 优质蛋白（鱼/肉/禽/蛋/奶/豆任一）+ 主食·碳水 + 蔬果·纤维。
- 说明：色系墙只看**膳食结构、不关联热量/慢病**（那些在今日卡的个人视角）。

**底部**：来源清单（复用「膳食参考依据/数据来源」同批权威出处·去重列）+ 免责重申。
