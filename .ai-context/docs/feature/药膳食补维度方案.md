## 〇、调研依据（权威层级）

- **① 药食同源官方目录（法定·最高可信）**：国家卫健委+市监总局《按传统既是食品又是中药材的物质目录管理规定》(国卫食品发〔2021〕36号)及历批具名公告，截至 2024-08 约 **106 种**"既是食品又是中药材物质"。**有官方文件、可结构化为白名单**，按名精确匹配——一期锚点。

- **④ 四气(寒/凉/平/温/热)/五味/归经**：**无国标、典籍间有分歧**（生熟变性、来源不一），只能作展示科普且显著免责，不可当"分级"。

## 一、要不要做 / 做到什么程度

**结论：谨慎地做（一期最小集），不缓、不全做。**

| 维度 | 判断 |
|---|---|
| 产品定位契合 | "枸杞/红枣/山药是不是养生"是家庭真实语言；中性、有官方出处的轻标签提升亲切感与差异化，不背离"帮家庭做饮食决策"北极星。 |
| 免责风险 | 全维度(四气/归经/功效)风险高易医疗化；但"药食同源"仅陈述"属卫健委公布的食药两用物质"=**纯事实陈述**，风险最低可控。 |
| 实现成本 | 药食同源=约106项按名匹配，**零算法零分级**，成本极低；四气需自建表+审校+接受"无标准答案"，成本中高。 |
| 红线兼容 | 只要**与现代营养/慢病评级严格隔离**(不进忌口/限量/评级/罚分)，就不违健康红线。 |

**反面提醒（避免过度设计）**：不要一上来建"食性+五味+归经+功效+体质"多维体系。中医维度价值在**克制点缀**，越全越像"中医诊疗工具"、越偏离家庭记菜定位、越难免责。

## 二、分期路线

**一期（低风险高价值·建议本轮做）**
- **锚点维度：药食同源标签(是/否)**——唯一有官方文件、可结构化、无分歧。
  - 食材详情"调养"信息后加一行"**药食同源**"轻标签(点开看"属卫健委公布的既是食品又是中药材的物质"+免责)。
  - AI 推荐新增"**食补**"过滤，一期即以"药食同源"为筛选内容(筛含/主打药食同源食材的菜)——**只正向展示筛选，不做健康判断**。
- 配套(可选低成本)：季节/场景食养**菜谱内容**，比给单食材贴"性"更贴家庭、更安全；一期紧张可只做标签。

**二期（评估后再定）**：四气纯展示(严格免责·只覆盖高频食材·不与慢病联动)；食补过滤扩到四气子选项；数据模型从"加列 A"演进到"独立表 B"。

**不做（红线·长期）**：❌归经 ❌具体疗效/功效断言(补气血/降压/去火/排毒/治…) ❌开处方式推荐 ❌中医维度接入慢病忌口/限量/评级/罚分(隔离红线)。

## 四、"食补"作为 AI 推荐过滤（产品设计）

**核心原则（不可动摇）**：**食补过滤只做"正向筛选展示"，绝不接入忌口/限量/慢病评级/推荐罚分。** 它回答"我想吃点药食同源/温补类的菜"，不是"我血压高该不该吃"——后者永远由现代营养体系(钠/GI/嘌呤/热量)单独负责，两套物理隔离。

1. **过滤项定义(一期)**：菜的配料命中药食同源白名单→进"食补·药食同源"结果集；可轻度分档(含≥1项入选、主料即药食同源排前)，**不引入分数罚分**，只做排序偏好。
2. **与现有过滤并列**：现有 营养·餐次·去重·风格 → 新增"**食补**"紧跟"营养"后，**可选、默认关闭不打扰**；与其他过滤取交集但**不改其他维度评分**，只缩候选/调排序；选项纳入 VM 粘性字段(参照风格/餐次的 `.copy` 保留，防重建 state 丢失)。
3. **免责承接**：打开食补过滤时面板/结果顶加免责条"食补分类为中医传统说法·仅供参考·非医嘱，仅按传统分类筛选展示，不构成健康建议"。
4. **空结果兜底(§9.6 不给死胡同)**：命中空→"没找到符合的食补菜"+可点动作(放宽为全部/换分类/去看药食同源食材)，或降级为"含最多药食同源食材前 N 道"；绝不因食补过滤把"该不该吃"渗进推荐。

## 五、食材详情"食补分类"展示

- **位置**：详情"调养"之后新增一行，仅有数据时显示。
- **一期内容**：轻标签"药食同源"+点开"属国家卫健委公布的既是食品又是中药材的物质"(纯事实可直陈)+底部免责"传统食养分类参考·仅供参考·非医嘱；药食同源指食品安全管理认定，非疗效背书"。
- **二期(四气)措辞**："传统食性认为偏温(中医传统说法·参考·非医嘱)"，来源不一标"说法不一"；**禁**"上火/去火/补/治"等，倾向中性。
- **来源标注**：药食同源→"据国家卫健委公告"(高可信)；四气→"传统说法·非国标·来源可能分歧"；**禁编造典籍出处，查不到即省略**。

## 六、数据与埋点

- **一期数据**：卫健委+市监总局历批公告累加具名清单(约106项，官网公告为准，二手仅交叉核对)，**完全结构化为白名单**按去空格名匹配。
