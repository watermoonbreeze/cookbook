# UX-CONSISTENCY-01：交互一致性、可访问性与 UI 迁移目录

> 状态：**RESEARCH**；所有 UI 实施批均须先产出 Apple-UX 可落地规范，本文不授权界面改动。  
> 覆盖：J21、J4/J5、J16、I-Mine/I-About、U3、1626、8559、J11/K14、J6、3099、K2/U2、NAV-COMPACT、MATERIAL3-UPGRADE。

## 1. 已知交叉事实

- AI 快捷记统一入口已有历史交付/真机验收，但“文本输入在旧 Material3 `ModalBottomSheet` 中长按系统菜单不可用”属于承载层问题；全屏承载是已定方向，不能用删自制粘贴按钮替代。
- `MATERIAL3-UPGRADE` 涉 Kotlin/Compose/编译器版本链及全项目大量 Sheet，必须单独在分支做兼容性证据，绝不作为任一页面改版的顺手升级。
- Timeline 月折叠、我的页分组、采购入口、搜索二级名称、适老模式均各自有导航/状态/无障碍语义，不能只凭截图确认。
- R1 餐次入口改动仍有 R10 真机项；任何新导航设计必须把这些回归纳入同一最终真机清单。

## 3. 共同不变量

| ID | 必须 | 禁止 |
|---|---|---|
| INV-UX-01 | 每个页面有明确入口、返回、加载、错误、空态和恢复规则。 | 用视觉合并隐藏不可达功能或丢失草稿。 |
| INV-UX-02 | 交互规格包含 dp、文字层级、窄屏/大字、触达/语义与深浅色。 | 仅交付截图或模糊“苹果化”描述。 |
| INV-UX-03 | 跨页面入口复用既有行为契约，业务状态在导航后保持一致。 | 复制业务逻辑或为导航临时绕过 Repository/UseCase。 |
| INV-UX-04 | 系统复制粘贴与无障碍优先；临时辅助按钮在替代能力经真机证明前保留。 | 因视觉简化删除唯一可用能力。 |
| INV-UX-05 | 框架升级是可逆兼容性实验，功能变更另批验收。 | 将依赖大版本升级与产品重构绑定提交。 |

## 4. 通用验证合同

每一批均须：Android 单测/构建；目标页 screenshot/布局检查；大字体、最窄支持宽度、深色、TalkBack；返回/重建/旋转；真实设备手势导航。涉及入口迁移还须覆盖原入口、深链、编辑上下文直达与新入口 2×2 分支。

## 5. 当前禁止事项

- 不在无 UX 规格时直接压缩导航栏或重排“我的”页。
- 不将 `MATERIAL3-UPGRADE` 当作修复单一 Sheet 的快捷方式。
- 不删除 AI 快捷记粘贴兜底，直至全屏/升级路径完成真实验证。
- 不把适老模式做成单纯字体倍率；需一并审查触达、密度、对比度和恢复性。
