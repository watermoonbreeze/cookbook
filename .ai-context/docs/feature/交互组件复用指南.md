## 二、新增的复用组件（本轮建）

| 组件 | 用途 | 规格 |
|---|---|---|
| **`UnsavedGuard`** | 未保存返回守卫统一封装(抽自 NewDishScreen 内联) | `UnsavedGuard(isDirty, onConfirmLeave){ requestBack -> ... }`：内部 `BackHandler`+"放弃未保存的更改？"弹框(放弃红字/继续编辑) |
| **`AppSnackbarHost`** | 统一保存/撤销反馈，终结每屏各建 `SnackbarHostState` | 挂 `MainScaffold`，`showMessage(text)`/`showUndo(text,onUndo)`；撤销走 `ActionPerformed` |
| **`EmptyState` +action** | 落实 §9.6"给下一步" | 加可选 `actionLabel`+`onAction`，有则文案下渲染次按钮 |
| **`FormBottomBar`** | 统一"保存/保存并继续"摆位 | `primaryText`+`onPrimary`(胶囊)+可选 `secondaryText`+`onSecondary`(次文字)；`navigationBarsPadding`+`WindowInsets(0)` |
| **`FoldSection`**(`ui/component/FoldSection.kt`) | 低频区**分类独立折叠段**(表单低频选填收纳)·食材编辑/菜品编辑共用 | `FoldSection(title, expanded, onToggle){ content }`：标题整行可点+chevron 旋转+仅展开渲染；通常包在 `InsetGroup{}` 白卡内(自带16dp屏边距)；折叠态用 `rememberSaveable(entityId)`(新建收起/编辑展开/有内容自动展开)。**🔴禁 content 内 `return@`**(SlotTable 崩)。取代旧 `MoreOptionsHeader`(单个大折叠·已废弃删除) |
