## 六、关键设计决策

1. **AutoGenContext 统一预取**：所有字典（食材名→id / 营养候选 / 分类 / 餐次 / 调料 / 别名）一次性加载，避免逐次 N+1 查询
2. **两阶段 API**：preview(只读) → 用户确认 → commit(原子写)，满足"确认入库"红线
3. **营养估算标注"自动估算·待核"**：IngredientNutrition.ref 写"自动估算·待核"，禁止当权威展示（INV-09）
4. **care 不自动断言**：新建食材 careFlag=PENDING_REVIEW，只继承归一命中库内食材已有 care（INHERITED）
5. **MultiDayRecorder 零破坏降级**：保留 recordAll 签名 + DayRecordResult/MultiDayRecordResult，内部委托 DayAutoGenerator
6. **K1c weekday→date_offset**：纯函数推算"最近过去的该星期几"，不含未来日期
7. **K1b 健康评价脱敏**：HealthContextBuilder 只传病种/年龄段/生命阶段·不传姓名/体检数值（待 L1 合规闸门后启用）
