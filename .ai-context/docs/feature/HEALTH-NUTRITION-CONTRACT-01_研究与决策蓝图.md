# HEALTH-NUTRITION-CONTRACT-01：健康与营养口径研究、ADR 与冻结门

> 状态：**DECIDE / RESEARCH**；不得据此改阈值、seed、用户可见健康评级或历史数据。  
> 覆盖：数据健康-905、J20、J9、J10、战略会商-429、2335、1248、6319、J3。

## 1. 现实基线

1. 当前历史/今日营养为**实时计算**：记录、菜品配料或食材营养数据变化会影响后续阅读结果；没有餐次营养快照的 schema/迁移合同。
2. `NutritionLevel` 已将高血压钠、高血脂饱和脂肪/胆固醇、糖尿病 GI、痛风嘌呤参与评级；`IngredientCrowdCare` 又将人工 care 规则作为更严的单向压制。两者必须作为一个整体审计，禁止单改其中一个阈值。
3. 当前说明已承认痛风/高血脂的部分数据需要临床审校；缺数据必须不误判，不可用扩充数据“洗白”人工限制。
4. 调味料的“限量”文案、成员多条件综合、生命阶段、视觉呈现和历史快照均会影响不同层：数据、算法、UI 与用户的既有理解，不能拼为一个代码批。

## 2. 已核对的权威证据入口

| 主题 | 可用的一级/权威入口 | 在本项目中的允许用途 | 禁止推论 |
|---|---|---|---|
| 一般成人盐/钠 | WHO Healthy diet：钠 <2g/d≈食盐<5g/d；国家卫健委减盐信息同样给出 5g 盐≈2g 钠。 | 审计现有盐/钠换算和公众说明的一致性。 | 不能直接推出个人每日目标、儿童/肾病等特殊人群阈值。 |
| 成人高血压食养 | 国家卫健委《成人高血压患者食养指南》：减钠增钾、盐逐步降至5g以下。 | 验证高血压“限盐/增钾”为健康教育方向。 | 肾病/高钾风险及药物交互不得由 App 自行处置。 |
| 一般膳食 | 国家卫健委公开的《中国居民膳食指南（2022）》相关材料。 | 作为食物多样、清淡少盐的参考页来源。 | 不将一般人群建议写成疾病诊断/治疗。 |
| 高脂血症 | 国家卫健委已发布成人高脂血症食养指南；国际指南可作补充比较。 | 建立“饱和脂肪/胆固醇应审校”的来源台账。 | 不以国际单一阈值替代中国人群口径，或建议药物/补剂。 |

完整链接与版本日期必须在实施前固化进 ADR/数据来源页；网络检索仅为证据定位，最终引用须由领域审校确认。

## 3. 必须独立作出的决策

| ADR | 选项 | 推荐的冻结顺序 | 不变量 |
|---|---|---|---|
| ADR-HN-01 历史营养 | A 实时；B 写入即快照；C 默认快照+显式重算版本 | 先列出现有 reseed、备份、报告、推荐、餐食编辑依赖，再选。 | 不得静默重写用户已发生餐食的可见营养；任何重算可见、可撤销/可追溯。 |
| ADR-HN-02 健康数据等级 | A 仅人工 care；B 仅数值；C 人工规则单向压制数值 | 以当前 C 为基线，补“何时允许放宽/缺失如何处理”证据。 | 没有数据不得判绿；人工 AVOID/LIMIT 不被数值数据降级。 |
| ADR-HN-03 调味料 | A 仍显示忌口；B 显示限量/少用且不从菜中剔除 | 先列盐、酱油等实际对象和当前页面文案，再冻结 UI 规范。 | 不把“限量”误导为无上限；不改变个人忌口的优先级。 |
| ADR-HN-04 多成员综合 | A 只分项；B 只综合；C 分项+“对我而言”综合 | C 可作为 UX 原型方向，先明确成员选择、并集/最严规则和解释。 | 不将不同成员的数据相加；综合结果可反查到成员与触发规则。 |
| ADR-HN-05 生命阶段 | A 仅科普；B 进入评价；C 进入推荐过滤 | 在权威分人群摄入量、免责声明和产品授权齐备后再选。 | 不把科普内容变成医疗建议或自动禁止普通食物。 |

## 4. 未来实施拆批与验证

1. `NUTRITION-SNAPSHOT-ADR-01`：只作依赖盘点、schema 方案和迁移/回滚演练；冻结前不得改表。
2. `CARE-RULE-EVIDENCE-01`：逐条来源版本、适用人群、缺失和冲突审校；每条输出可复核证据，非“覆盖率”。
3. `SEASONING-COPY-UX-01`：只改经确认的调味料展示和文案，必须有 UX/无障碍审查与“限量≠无需控制”测试。
4. `MULTI-PROFILE-VERDICT-01`：分项与综合的纯函数、来源解释、成员切换和回归矩阵；不触及疾病阈值。
5. `LIFE-STAGE-SCOPE-ADR-01`：先定义范围、风险提示、专业审校/产品授权；未授权不编码。

共同验证：固定成员/食材/餐食 fixture；每次阈值或来源变动比较旧/新 verdict；无数据、冲突规则、多成员、调味料、历史记录编辑和 seed 更新均需覆盖。所有用户可见健康结果都要保留“仅供参考、非医嘱”边界。

## 5. 当前禁止事项

- 不直接根据网络搜索修改钠、钾、GI、嘌呤、饱和脂肪或胆固醇阈值。
- 不将“青菜/鱼油/鸡毛蛋”等边界食物一次性批量判红或判绿。
- 不为实现快照悄悄改变历史报告、备份或推荐结果。
- 不将生命阶段/疾病建议作为诊疗或补剂推荐。
