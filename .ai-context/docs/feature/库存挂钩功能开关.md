# 库存挂钩功能开关

> 2026-07-16 无人值守落地。经探索(落点) + Apple-UX 设计门禁(降级一致性) + Google 审查门禁。

## 一、目标
给"不做库存管理"的家庭一键去噪：加"库存挂钩"总开关（我的→功能设置，**default 开=保留现有行为**）。关掉后全 App 不再出现"缺料/采购/现在可做/库存不足"标注、库存相关页面/Tab/推荐档降级。

## 二、设计铁律（Apple-UX 门禁）
- **关掉后到处彻底无痕，绝不半遮半掩**——一个开关一次决策。
- **变灰与标注同生同灭**：缺料菜的 alpha<1 是"缺料做不了"语义，库存关了没"缺料"概念，必须恢复 alpha=1（否则"关了还灰"莫名）。
- 策略：**源头 gate 数据返空 + 三处结构显式隐藏**。

## 三、落点与 gate（6 处消费点，全部对照检查清单）
| 处 | 文件 | 关掉后 |
|---|---|---|
| 开关本体 | FeatureSettingsVM/Screen | 库存占位 PlaceholderRow→SwitchRow「库存挂钩」，InsetGroup 标题"库存"→"库存管理" |
| ①菜品详情库存洞察 | DishDetailViewModel | 注入 prefs，关则 servings=emptyMap→usingPantry=false→采购/缺料/可做整块不判(源头 gate) |
| ②食历卡缺料标注+变灰 | DayMealCardView | cardAlpha/cellBelow gate：关则不变灰、不显"采:/缺:" |
| ③AI周期规划缺料标+变灰 | AiPlanScreen(DayCard) | 同上 |
| ④采购清单入口 | MineScreen | 隐藏"采购清单"SettingRow + 其 InsetDivider |
| ④采购清单页(深链防御) | ShoppingListScreen | EmptyState"采购清单已关闭…" |
| ⑤库存推荐档 | AiRecommendScreen | segmented 隐藏"库存推荐"档(label 分发防索引错位) + LaunchedEffect 回落 PANTRY→RANDOM |
| ⑥食材"库存"Tab | IngredientPickerScreen | 过滤掉 PANTRY Tab + LaunchedEffect 停在该 Tab 则回落 RECENT |

- **RecommendationDataSource(shared) 未改**：PANTRY 模式因 UI 隐藏该档 + 回落而不可达，无需 gate shared 引擎（减小 blast radius）。
- **实现模式**：UI 消费点复用既有 `koinInject<PreferenceRepository>() + observeFlag(PANTRY_HOOK_ENABLED, default=true) + collectAsStateWithLifecycle(true)`（与 DayMealCardView 营养色系开关同款）；各处 default 均传 true（避免老用户库存突然消失）。
