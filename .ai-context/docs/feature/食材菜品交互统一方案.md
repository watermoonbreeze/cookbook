## 现状关键结论（自查代码）
- **菜系二级左栏来由**：早前自主提交 `6ca2d88 菜系做成左侧一级分类栏`，**非 UX 定稿**，可推翻重做。
- **"切 Tab 一直跳"根因**：菜品页搜索+4Tab 塞进会滚的列表头；且**只有"菜系"Tab** 用 `Row{左栏|列表}`、其它 Tab 纯列表 → 切 Tab 布局在两形态间跳变。
- **食材页（统一标准）结构**：`搜索(常驻) → 一级 FilterChip(固定不滚) → Row{左120dp竖分类树 | 右3列网格} → 底栏`，一级固定、二级左下、结构对所有分类一致 → 不跳。
- **选择菜品(DishPicker)**：纯搜索+最近/喜爱chips+单列 checkbox 列表，**零分类导航**，与选择食材差异大。
- **可复用餐食卡**：`ui/component/DayMealCardView.kt`（入参 `DayMealCardData`）。

## 本轮落地 B（背景统一·以菜品为准）
- **操作逻辑**：`IngredientPickerScreen` 根 Surface `surface`→`background`（分组灰，与菜品页 `background` 一致）；左侧分类树 `secondaryContainer`→白 `surface` + 右侧 1px `outlineVariant` 分隔条（M3 1.1.2 无 VerticalDivider，用 Box 竖条）；`CategoryItem` 选中态 `secondaryContainer`→浅橘 `primaryContainer`（原选中色与旧左栏底同为 secondary 系、几乎看不出选中，改后在白栏上突出）。层次=灰底(background)→白栏/白卡(surface)→浅橘选中(primaryContainer)，全主题语义 token、明暗自动成立。
- **影响面**：食材管理页 + 选择食材弹窗（共用组件）同步统一。
- **用户验证**：食材页整体背景变为与菜品页一致的分组灰；左侧分类栏为白底、选中项浅橘高亮、与右侧内容有 1px 分隔；深浅色模式都协调。

## 本轮落地 D（添加餐食保存预览）
- **操作逻辑**：`AddDayFoodScreen` 保存按钮 onClick 改 `if(isPlan) previewOpen=true else vm.save()`——**仅"保存计划"弹预览**，实录(记餐)高频操作**直存不加确认**（守"快速记录每餐/少操作"红线，此为对 Apple-UX"计划实录都预览"建议的**刻意收敛**，贴合用户原话只提"保存计划"）。预览用 `ModalBottomSheet`（§7 底部 sheet 承载确认）+ 现成 `DayMealCardView` 渲染由草稿(`state.mealBlocks`)组装的 `DayMealCardData`（所见即首页/食历那张卡）+ 底部"确定保存 / 返回修改"。
- **口径**：预览 filter（mealTypeId!=null && dishes 非空）与保存口径一致；按钮 enabled=canSave 保证不弹空卡；只读预览不传编辑/复制/删除回调（能力由回调决定 §9.3）。
- **用户验证**：首页+号加餐食 → 填计划 → 点"保存计划" → 底部弹出预览卡（同首页计划卡样式）→"确定保存"才落库、"返回修改"回表单；实录（非计划）点"保存"仍直接保存不弹预览。

## 第二轮落地（A + C核心 + D收尾·2026-07-17）
- ✅ **A 菜品页重构**：一级 SegmentedControl **移出滚动列表→固定在 LargeTopAppBar 下方**（不随列表滚），消除"切 Tab 搜索/Tab 跳变"根因（旧版 Tab 在列表头 + 只有菜系 Tab 带左栏→切 Tab 布局在两形态间跳）；搜索/计数仍下沉列表头随内容滚驱动大标题折叠（§9.15）；菜系二级左栏保留、外层结构对所有 Tab 一致。`dishHeaderItems` 去 Tab item、`letterHeaderCount` 4→3。Google 审查无阻断，采纳要点4：切 Tab 后 `listState.scrollToItem(0)` 重置滚动位（菜系/非菜系档共用同一 listState，避免切档停非顶部）。
- ✅ **C 核心·选中态勾选圈**：`DishRow` 多选态 Material Checkbox→**勾选圈**（复用 IngredientCard 同款 22dp 圆圈·苹果 Photos 式），选择菜品与选择食材选中手势/视觉统一。仅影响选择菜品(multiSelect)，菜品页(showCheckbox=false)不受影响。
- ✅ **D 收尾·预览餐次按时间排序**：`AddDayFoodScreen` 预览 `.filter{it.canSave}` 后加 `.sortedBy { it.mealTime }`（仅展示序不影响保存）。
