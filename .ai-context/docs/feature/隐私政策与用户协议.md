# 一、隐私政策

## 引言
欢迎使用「今天吃啥」（以下简称"本应用"）。本应用是一款帮助家庭记录每餐、管理饮食、并根据你的记录与健康情况推荐"今天吃什么"的工具。我们把**保护你的隐私放在第一位**：本应用采用"本地优先"设计——**你录入的饭菜、食材、餐食记录、健康档案等信息，默认只保存在你自己的设备上，不会上传到我们的服务器**。请在使用前阅读并理解本隐私政策。

## 1. 我们收集和处理哪些信息

### 1.1 你主动录入、且仅存于本机的信息（不上传）
- **饮食数据**：菜品、食材、每餐记录、菜单、库存、采购清单、收藏等。
- **健康相关信息**：你为家庭成员设置的健康档案（如慢病调理项、生命阶段、忌口食材）、身体数据（身高体重等）。
- **家庭成员信息**：你添加的成员名称与其上述档案。

> 以上信息**全部只保存在你设备的应用专属存储目录内**，我们**不收集、不上传、不能访问**。卸载应用或使用系统"清除数据"即会删除。你可通过应用内的"备份/同步"功能自行导出（走系统文件选择器，由你决定存到哪里）。
>
> 需要说明：以上"不上传"指**默认状态**。若你在「AI 设置」中自行配置云端 AI 模型密钥并启用，为提供该功能，相关必要信息会发送给你选择的云端 AI 厂商（发送范围见下文 1.4 节，且可随时关闭）。

### 1.2 匿名使用统计信息（需你同意才开启·默认关闭）
为了解产品是否好用、改进体验，在**你明确同意**后，本应用会收集**去标识化的行为统计**，经第三方统计服务（友盟+ U-App，见第 3 节）上报。**仅包含以下内容**：
- 打开应用、首次启动（时间戳 + 一个本机随机生成的匿名标识）；
- "记了一餐"（仅餐次类别：早/午/晚/加餐，**不含菜名、给谁、日期明细**）；
- 请求推荐 / 采纳推荐（仅来源类别：库存/随机/AI，**不含推荐了什么菜**）；
- 出现过忌口提示（仅"是否出现过"的布尔值，**不含病种、忌口的菜或食材**）；
- 使用了哪个功能区（预设的功能区名称，**不含具体页面内容/参数**）；
- 是否设置过健康档案（仅"是否设置"的布尔值，**不含病种、忌口、身体数据**）。

> **我们绝不通过统计上报你的任何饭菜内容、健康明细、身体数据或成员信息。** 匿名标识为本机随机生成，不含任何设备硬件标识（不采集 IMEI/MAC/OAID 等），无法关联到你个人；卸载重装即变为新的标识。你可随时在"我的 → 匿名使用统计"关闭，关闭后不再上报。

### 1.3 设备权限与用途
- **网络（INTERNET）**：用于（a）当你自行配置了 AI 模型密钥时的云端推荐；（b）你同意后的匿名统计上报。不配置、不同意则不产生相关网络请求。
- **通知**：用于烹饪计时、临期提醒等你开启的提醒功能。
- **相机（如你使用扫码/拍照相关功能时）**：仅在你主动使用时申请，用于对应功能，不用于其他用途。
- **存储**：数据存于应用专属目录，无需额外存储权限；导出/备份时通过系统文件选择器由你授权目标位置。

### 1.4 云端 AI（默认关闭 · 需你自行配置密钥并单独同意）
云端 AI 功能**默认关闭**，不会向任何厂商发送数据。只有你在「我的 → AI 设置」中**自行配置云端 AI 模型密钥并启用**后才会开启，且首次启用前会**弹窗征求你的同意**。

- **启用后会发送**：在手食材名（比如"西红柿、鸡蛋"）、粗略的健康标签（比如"忌高嘌呤"）、候选菜名、你在 AI 记一餐里输入的那句话。
- **不会发送**：姓名、账号，体检数值、病历、用药记录，照片，完整健康档案、历史餐食。
- **接收方**：你在 AI 设置中选择的模型厂商（如智谱 / DeepSeek / 通义千问 / 月之暗面），相关请求由其云端服务处理。
- **关闭方式**：可随时在「AI 设置」中关闭云端 AI（可保留或删除密钥），关闭后不再发送任何数据，不影响其余本地功能。

## 2. 我们如何使用信息
- 本机数据：仅用于在你设备上实现记录、查看、推荐、忌口提示等应用功能。
- 匿名统计：仅用于聚合分析产品的留存、活跃、功能使用与推荐采纳等趋势，**只看总体趋势、不针对个人画像**，用于改进产品。

## 4. 第三方 SDK
本应用集成 **友盟+ SDK**，用于上述第 1.2 节的匿名使用统计。按监管合规要求披露如下：

- **使用 SDK 名称**：友盟+SDK
- **提供方**：友盟同欣（上海）网络科技有限公司
- **服务类型**：数据统计分析（帮助我们了解产品使用情况、改进体验）
- **收集个人信息类型**：设备信息（IMEI / Mac / Android ID / IDFA / OPENUDID / GUID / SIM 卡 IMSI / 地理位置信息）
- **隐私权政策链接**：https://www.umeng.com/page/policy

**我们的最小化承诺**：我们已按友盟合规指引配置——**仅在你同意本隐私政策后才初始化该 SDK 并开始采集**（延迟初始化），并**关闭其非必要的设备标识采集**；我们通过该 SDK 上报的只有第 1.2 节所列的去标识化行为事件，**只看总体趋势、不做用户画像、不用于识别你个人**。上表中的"收集个人信息类型"为友盟 SDK 依监管要求需声明的**可能采集范围**，我们已尽可能关闭其中非必要项。

除上述统计用途外，本应用**不接入广告 SDK、不做用户画像售卖、不与第三方交换你的个人信息**。

## 5. 数据存储与安全
你的数据存储在设备的应用专属目录内。我们建议你定期使用应用内备份功能导出数据妥善保管。请注意：由于数据在本地，若设备丢失、损坏或卸载应用而未备份，数据可能无法恢复。

## 6. 你的权利
- **随时关闭匿名统计**："我的 → 匿名使用统计"，关闭即停止上报（撤回同意）。
- **访问 / 导出 / 删除**：应用内可查看和管理你录入的数据；可导出备份；卸载或清除数据即删除本机全部数据。
- **撤回同意**：关闭统计开关即撤回对匿名统计的同意。

## 7. 未成年人保护
本应用面向家庭日常饮食管理，不定向面向未成年人收集信息。若你是未成年人，请在监护人指导下使用。

## 8. 政策更新
我们可能适时更新本政策。更新后会在应用内以适当方式提示，重大变更将再次征得你的同意。

## 9. 联系我们
如对本隐私政策有任何疑问，可通过 kvssxd@126.com 与 个人开发者 SXD 联系。
