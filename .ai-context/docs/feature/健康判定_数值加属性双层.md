# 健康判定标准：营养数值 + 食材属性 双层

> [AI生成] 2026-07-22 用户确立。**核心：判定食材对慢病的宜忌，不能只看营养数值，还要看「食材属性」，两者取更严。** 以后所有食材、所有健康指标都按此标准处理。

## 一、规则（固化·加食材门禁）

**判定 = 数值层 + 食材属性层，取更严者（单向只升不降）。**
- **数值层**：嘌呤/GI/钠/饱和脂肪/胆固醇 的 mg 数分级（`NutrientBands`）。
- **属性层**：代谢机制/加工工艺/隐藏成分的风险，用 care 规则（`ingredient_care_rules.json`）承载 → `IngredientCrowdCare` 把 care 的 AVOID/LIMIT **单向压制**数值判级（数值判绿但属性该避免的→压成红/黄）。
- **架构已支持**（`IngredientCrowdCare.evaluate` 即此双层实现）。

**🔴 门禁**：加任何食材 / 营养数据时，必须两步——①录营养数值 ②评估「食材属性风险」并配 care 规则（带权威指南 ref）。**缺一不可**，不能只填数值就判可食（否则果糖/酒精/反式脂肪等"数值看不出的风险"会漏判）。

## 二、为什么"数据只是一部分"（数值层的固有盲区）
成分表只测"含什么成分、多少 mg"，测不出：
- **代谢机制**：果糖促尿酸生成（嘌呤=0）、酒精抑制尿酸排泄（啤酒范式）
- **加工工艺**：反式脂肪（无字段）、精制淀粉升 GI、腌制隐形盐
- **天然 vs 添加**：添加糖（成分表把天然糖和添加糖算一起）
→ 纯数值必然漏判，属性层必须兜底。

## 三、整体审视（各指标 × 数值层 × 属性层 × 缺口）
| 指标(病种) | 数值层 | 属性层 | 状态 / 缺口 |
|---|---|---|---|
| 嘌呤(痛风) | purine 数值 + HIGH_PURINE 关键词 | care(酒 avoid/含糖 limit·已补) | ✅ 最完善 |
| GI(糖尿病) | gi≥70 数值 | care(含糖 avoid/limit·已补) | 🟡 精制加工属性可深化 |
| 钠(高血压) | sodium 数值占比 | care(腌制/加工肉) | ✅ 较完善 |
| 饱和脂肪(高血脂) | satFat 数值占比 | care | 🔴 **反式脂肪无字段** |
| 胆固醇(高血脂) | cholesterol 数值 | care(内脏部分) | 🟡 高胆固醇属性可补 |
| 添加糖(糖尿病/脂肪肝) | ❌ **无字段** | care(含糖·已补部分) | 🔴 成分表不分天然/添加 |
| 草酸(肾结石) | ❌ **无字段** | ❌ 无 | 🔴 待建(若上结石档案) |

## 四、数值层根本没有字段的（**必须**靠属性层）
`ingredient_nutrition.json` 只有 16 个字段，**没有 transFat / addedSugar / oxalate**：
- 🔴 反式脂肪 → 高血脂（比饱和脂肪更该警示·却无数值）
- 🔴 添加糖/果糖 → 糖尿病/脂肪肝（成分表不分）
- 🔴 草酸 → 肾结石
→ 这几类**只能**靠食材属性 care，纯数值完全无法判定——最能印证"数据只是一部分"。

## 五、方案建议
### 方案 A · 渐进（推荐先做·低成本·用现有架构）
固化门禁规则 + 用现有 care 机制补齐属性缺口（反式脂肪→高血脂、高胆固醇、高草酸），像含糖类那样每条带指南 ref、保守分级。**快、低风险、立即见效**；代价=属性层仍是人工 care 规则，加食材要人工评估属性。

### 方案 B · 中期（结构化·需立项·可选）
**食材属性标签体系**：给食材打结构化「属性标签」（含酒精/高果糖/添加糖/反式脂肪/腌制加工/浓汤/高胆固醇/高草酸）→ 建声明式「属性→病种 care」映射规则表（如 `含酒精→痛风avoid+血压limit`）→ 加食材只需打标签，自动套用 care。
- **优点**：统一（不再分散于 HIGH_PURINE 关键词 + 人工 care + 数值三处）、加食材不易漏（打标签是门禁）、属性标签可复用于推荐/搭配/展示。
- **代价**：中等重构（属性枚举 + 映射表 + 迁移打标）。

### 方案 C · 长期（可选）
B + 补 transFat/addedSugar/oxalate 数值字段——但这些成分表多无数据，不如属性标签实在。

**推荐路线：A（立即固化+补缺口）→ 中期视规模演进到 B（属性标签体系）。** C 不优先。

## 六、决策点（交用户）
1. **方案方向**：先走 A 补齐缺口即可，还是中期立项 B（属性标签体系）？
2. **A 的补漏范围**：反式脂肪/高胆固醇/高草酸 现在补吗？（反式脂肪食材多不在库·可随"加工食品"入库时配）
