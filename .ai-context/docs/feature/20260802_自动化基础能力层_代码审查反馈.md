**问题描述**：

- `createGenerator()`（`:73`）又 `RepositoryTestDatabase.create()` 建 **空的 DB-B**

- `commit CREATE`（`:200`）：ctx 在 DB-A 找"牛腩"→CREATE，commit 写进空 DB-B 恰好也没有→凑巧通过，是「绿但没测到」

**无法保护的不变量**：INV-05（ref="自动估算"）、INV-06（两阶段写库语义）、INV-07（source="auto"）

**修复步骤**：
```kotlin
// 方案：把 db 从 createContext() 中取出，作为测试类级别共享对象

class IngredientAutoGeneratorTest {

    private lateinit var db: CookbookDatabase    // 共享同一 DB
    private lateinit var ctx: AutoGenContext
    private lateinit var generator: IngredientAutoGenerator

    @BeforeTest
    fun setUp() = runBlocking {
        db = RepositoryTestDatabase.create()
        // 种入基础数据（单位/餐次/分类/食材/营养），与原 createContext() 内容相同
        // ...（照搬原 createContext 的种入逻辑）
        val aliasResolver = IngredientAliasResolver.fromJson("""{"蕃茄":"番茄","西红柿":"番茄"}""")
        ctx = AutoGenContext.load(db, aliasResolver)
        generator = IngredientAutoGenerator(IngredientRepository(db), NutritionRepository(db))
    }

    // 原有 T01/T03/T04/T05 测试保持不变，去掉 createContext()/createGenerator() 调用

    @Test
    fun `T07 preview不写入DB`() = runBlocking {
        val q = db.cookbookQueries
        val countBefore = q.selectAllIngredientNames().executeAsList().size
        repeat(3) { generator.preview(SemanticIngredient(name = "新奇食材$it"), ctx) }
        val countAfter = q.selectAllIngredientNames().executeAsList().size
        assertEquals(countBefore, countAfter, "preview 不应写入任何食材")
    }

    @Test
    fun `commit CREATE 建食材并验证source和ref`() = runBlocking {
        val preview = generator.preview(SemanticIngredient(name = "牛腩"), ctx)
        assertEquals(ResolveKind.CREATE, preview.resolution)
        val id = generator.commit(preview)
        assertTrue(id > 0)
        // ↓ 真正验证落库：source="auto"（INV-07）
        val row = db.cookbookQueries.selectIngredientById(id).executeAsOneOrNull()
        assertNotNull(row)
        assertEquals("auto", row.source)
        // ↓ 验证营养 ref="自动估算"（INV-05）
        val nutrition = db.cookbookQueries.selectIngredientNutritionById(id).executeAsOneOrNull()
        assertNotNull(nutrition)
        assertEquals("自动估算", nutrition.ref)
    }
}
```

### B1 ⬜ isSeasoning 误把未分类食材当调料（`IngredientAutoGenerator.kt:96`）

**文件**：`shared/src/commonMain/kotlin/com/sxdbsm/cookbook/domain/autogen/IngredientAutoGenerator.kt`

**问题**：CREATE 分支 `isSeasoning = nameKey in ctx.seasoningNames || group == null`
`group == null` 意味着"FoodGroup.classify 未能识别的食材"，如"魔芋丝""藜麦"等生僻食材，会被当调料给 3g 默认克数，导致营养摄入严重低估。

**修复**：
```kotlin
// 删掉 || group == null
val isSeasoning = nameKey in ctx.seasoningNames
```
