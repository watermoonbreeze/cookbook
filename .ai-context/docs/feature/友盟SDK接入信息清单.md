本项目 debug 与 release **统一用同一个 keystore**（根目录 `cookbook.jks`，alias `cookbook`），所以下面这一组指纹对开发包和正式包都适用。

| 项 | 值 |
|---|---|

| **签名 MD5**（**不带冒号**，部分平台要这种） | `97C86944 80030D42 0E24F66A 60D27AC2` → `97C8694480030D420E24F66A60D27AC2` |
| **SHA1** | `AE:C8:8C:1D:A2:01:68:40:6E:EE:0C:D0:08:18:4F:63:AE:B7:FD:E1` |

| 证书 Owner | `CN=sxd, OU=personal, O=owner` |
| 签名算法 | SHA256withRSA |

> U-App **基础统计**通常只要 **包名 + AppKey**，MD5 不是必填；但友盟部分安全/合规校验或其他服务会要 MD5，故一并给你。**若表单要 MD5，优先填"带冒号"那行**。
