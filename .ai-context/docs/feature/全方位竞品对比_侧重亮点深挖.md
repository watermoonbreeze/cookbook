## 〇、三视角一句话共识（罕见地高度一致）
> **别在竞品最强的"减重×录入"战场用 60 分能力硬拼；把力气全压在无人占据的"家庭×慢病×生命阶段×中式决策器"上——用「成员化红绿灯」让差异化一眼可感，把已落地的结构化引擎「正向兑现到推荐质量」，用「零录入 aha 前置」让用户熬得过冷启动。聚焦，是小团队唯一的护城河施工法。**

- **PM**：我方"是什么产品"独占领先、"用起来爽不爽"落后；分主次 all-in，别平均用力。
- **运营**：我方主动弃了减重派的成瘾武器，留存必须押"每天打开都有真价值"（家庭吃饭天然高频持久）。
- **架构**：竞品护城河=感知+规模（资本快变量·可堆）；我方护城河=结构化决策（领域知识×工程慢变量·难追），**两条技术曲线不同维度**。

## 二、该 all-in 深挖的侧重与亮点（三视角交叉·带优先级）

### 🥇 P0 进攻 · 头号叙事主线：**成员化健康红绿灯**（家庭分摊 × 慢病忌口的"可感化"）
**三视角一致指向它**：PM=最硬最独占最可感的差异化；运营=唯一能做出竞品做不出的 aha 瞬间；架构=底座已成（`IntakeCalculator` 三维折算 + `HealthRuleEngine` 双层忌口·均 commonMain 已落地）。
- **一个画面撑起整个定位**："同一道红烧肉，对爸爸(高血压)黄灯、对爷爷(痛风)绿灯、对你绿灯"——竞品**结构性做不到**（个人单位 + 无双层引擎），且用户一眼就懂。
- **深挖方向**：红绿灯落到**每个动线**（记菜/选菜/详情/推荐结果/今日卡），做到"记一餐顺手就看到全家红绿灯"。触发=已录 ≥2 成员且 ≥1 有健康档案时点亮分人色，否则退化单色不打扰。
- **红线**：色是**服务性告知**（"帮爷爷避开高嘌呤"）非评判、不贴病人标签、不制造家人健康对比焦虑（文案过 copywriter）。

### 🥇 P0 深投 · 把结构优势"正向兑现到推荐质量"（架构+PM 共同指向·最高技术杠杆）
不是新建能力，是**把已落地的结构化引擎从"呈现"用到"推荐打分"**——这是把独占的数据模型优势转成用户可感的推荐质量：
- **① 多成员折算贯穿推荐评估**（非只今日卡呈现）：多成员忌口/营养需求**并集参与推荐打分**，让"给家庭推荐"真正用上 `IntakeCalculator` 结构。
- **② 忌口引擎扩正向"推有利菜"**（接已登记待办·line53）：从负向剔除扩到正向加分（高钾低钠/低嘌呤利尿/低脂高纤/孕期铁钙/老人优质蛋白），复用 `HealthRuleEngine` 结构、边际成本低、差异化高。**走权威方法论优先**（食养指南/膳食指南生命阶段篇整理进膳食参考依据再引用）。

### 🥈 P1 惊喜 · 最稀缺空档：**生命阶段"调养"正向推荐**
【事实】竞品连慢病类都没做生命阶段——比慢病忌口更稀缺。但现状"有壳无核"（档案已有·正向待深化）。
- **先做透一个场景胜过铺五个**：孕/哺乳/婴幼/老人各挑 1 个高频刚需（如"老人优质蛋白细软菜""孕期叶酸铁钙"）配权威 ref 做透。
- **运营=被动发现优于主动推送**：在用户已在用的动线里自然显现（标了老人→推荐自动带该视角），**禁"你怀孕了还不来看"式焦虑触达**。可延后（服务子人群）。

### 🥉 P0 守门（非亮点但致命）：**基础功能顺手度**
【推断待验证】差异化再强，记一餐点 8 次就留不住。**建议每迭代留固定配额**给"少一步/少一个必填/更好默认值"打磨，而非"做完功能再优化体验"。enabler 4 已点破"最易忽视最致命"。

> **侧重裁决一句话**：**进攻用成员化红绿灯（P0）+ 把引擎正向兑现到推荐质量（P0 深投）；惊喜用生命阶段调养（P1·做透一个）；底盘用基础顺手度（P0 守门）。其余能力（色系墙/周期推荐等）维持不加码。**

## 四、该放弃 / 不该跟（陷阱清单·凡拖进"减重派主场"或"为不存在平台预抽象"的都否决）

| 诱人能力 | 判定 | 理由（三视角） |
|---|---|---|
| **拍照识别热量 all-in** | ⚠️不 all-in·仅云 AI 增值可选层 | 中式家常糊在一起 CV 难分、份量估算精度低污染下游；是减重派核心武器=用短板拼长板、把自己拉进人家主场；即便做也识别后**回落我方结构化体系再判定**，别绕过引擎 |
| **百万级预包装 SKU 大库** | ❌放弃（已定） | 数据商生意·违本地优先·中式家常天然弱·库大≠会用（有数值≠有忌口判定） |
| **对接超市/电商导购** | ❌放弃（已定） | 无公开 API·稀释纯粹·招反感 |
| **社区/UGC 菜谱** | ⚠️不跟 | 与本地优先隐私+小团队克制根本冲突·家庭健康决策价值不来自社区 |
| **打卡/连胜/排行榜/愧疚召回** | ❌放弃（红名单） | 违苹果诚实伦理（§5.4） |
| **"热量数字"当主叙事** | ⚠️不做主线 | 一旦叙事变"算卡路里"就滑向减重派同质化·丢"家庭健康管理"健康观（热量默认开但不当核心） |
| **CMP-iOS / TCA / Decompose / 全量 MVI** | 🔴过度设计负债 | 为不存在平台预抽象·CMP 牺牲体验(命门=顺手)·本项目无 MVI 规模痛点（架构红线） |

## 五、最大风险与解法（收敛）
1. **差异化"感知不到"**（最致命）：深度价值需先投入、录入又高 → **aha 前置零录入 + 家庭渐进不强制**。
2. **无账号=弃传统召回/裂变**：→ 用**本地高频真价值**补（每日推荐首屏=替代打卡的留存主引擎·变化来自真实库存/历史/忌口·禁伪造新鲜感）+ 本地事件通知（临期/计时·唯一诚实召回渠道）。
3. **健康免责 vs 差异化锋利度张力**：红绿灯越想有说服力越易滑向"健康判决"→ 守"陈述事实不下判决"、每次健康文案过 copywriter。
4. **小团队战线过宽**：→ 聚焦即战略（一期压两个 P0 + 生命阶段做透一个·其余不加码）。
