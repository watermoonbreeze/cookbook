# 营养数据治理方案（一期 part2 关键路径）

> [产品经理拍板稿 2026-07-16] 现状数字实测自 `seed/ingredient_nutrition.json`(440行) 与 `ingredients.json`(440种)。
> 定位：营养指标准确=AI 健康推荐地基，也是健康免责风险最高的一块，PM 全权把关。

## 一、现状盘点（实测，关键修正）
- **营养行覆盖率已 100%**(440/440)——真问题**不是补缺行**，而是：提准确度 + 去 pending + 补新指标。
- 字段缺失：kcal/宏量/纤维/钠钾钙/**嘌呤 purine 全 0% 缺失(P4 数据已齐)**；**GI 缺 70 条(15.9%)但多为合理 N/A**(肉/水产/油/调料不含可消化碳水,GI 无意义,**不应强补=编造**)——**真需补 GI < 15 条**(8 叶菜给惯例低值 + 少量豆制品/主食复核)；pieceGram 缺 64.5%(非营养重点)。
- **review 分布**：verified **278(63.2%)** / pending **162(36.8%)**——162 pending 是最大工作量。pending 按类:肉35/菜25/主食24/调料22/水产14/豆坚果9/方便食品8/其他7/菌藻6/水果5/乳4/蛋3。
- **Schema 缺口(比数据更硬)**：`IngredientNutrition`/`NutritionTotals` **无 saturatedFat/cholesterol/sugar**→**P3 高血脂、P2 添加糖维度被 schema 阻断**(需 `.sqm` 迁移)。
- 消费方 `NutritionLevelEvaluator`：**P1(热量+钠)已实装**；P2(GI/糖 DIABETES)/P3(饱脂/胆固醇 HYPERLIPIDEMIA)/P4(嘌呤 GOUT)枚举已定义但**无判定分支**。**P4 purine 数据 100% 齐，纯口径落地即可解锁，零补数据。**

## 二、权威数据源（按指标）
- 能量/宏量/纤维/矿物质：**中国食物成分表 标准版第6版**(一手→verified)；USDA FDC 仅交叉核对(标注,不单独作 verified)。
- NRV/声称阈值：GB 28050-2011。
- **GI**：分级 **FAO/WHO**(低≤55/中/高≥70,**非 WS/T 652-2019**)；数值《中国食物血糖生成指数表》(杨月欣)+悉尼GI库交叉;叶菜无实测给惯例低值须标"惯例·非实测"。
- 钠/添加糖限量：膳食指南2022(钠2000/添加糖25理想·50上限)+高血压指南2018(2400)。
- **嘌呤**：成分表实测值(展示)+WS/T 560-2017 定性清单;**三级 25/150 无国标**→用必标"非国标·惯例",**推荐只做定性清单**。
- 饱脂/胆固醇(血脂)：成分表分项(不全)+USDA交叉;限量 血脂指南2023(饱脂供能<10%,高血脂<7%)/食养指南2023(胆固醇<300,高<200)。**数据可得性最差,排最后。**
- **免责总纲**：健康数据"AI 参考整理·非权威核对";只有对到一手权威成分表/国标才 `verified`;查不到省略不编造;不确定标 `pending`+ref;禁编造出处;全局"仅供参考·非医嘱"。

## 三、补全优先级（按"解锁慢病维度"排序）
- **批次0(零补数据,立即·解锁 P4 痛风)**：purine 已齐,落地 GOUT 定性清单(内脏/浓肉汤/沙丁鱼凤尾鱼/部分贝类,引 WS/T 560-2017 类别,定性非数值)+evaluator GOUT 分支+单测。**最高杠杆。**
- **批次1(P2 GI·解锁糖尿病GI侧)**：补 staple(24)+fruit 的 gi 达 verified(主食/水果对糖尿病最关键)；8 叶菜给惯例低值(estimated);**不碰添加糖**(家常食材多为0,先只上GI)。evaluator 加 DIABETES GI 分支+单测。
- **批次2(去 pending·提准确度)**：162 pending 逐步核准 verified,序:主食24→蔬菜25→水产14→肉35→其余。核对既有值对不对一手成分表,对不上则修正升级。
- **批次3(P3 血脂·需先扩 schema,建议延到 part2.5)**：加 saturatedFat/cholesterol(需一次改全 CREATE+`.sqm`+seed schema+NutritionTotals+评级分支);补动物性食物(肉/水产/蛋/乳/油~130种);迁移升级推演单测。

## 四、口径与分级
- 单位每 100g 可食部;同名多形态 ref 注明取哪条(生/熟)。
- **review 三态(采纳引入 estimated)**：verified(一手权威)/**estimated(有据非一手:惯例/换算/USDA交叉)**/pending(无据·不进评级退多样性)。
- 阈值：GI FAO/WHO;钠 2000/2400;添加糖 25/50(P2暂不启用);饱脂<10%(高<7%)/胆固醇<300(高<200)(P3);**嘌呤不做数值三级,走定性清单**。
- 免责措辞模板 + 统一脚注"健康数据为 AI 参考整理·非权威核对,仅供参考,不作医疗建议"。

## 八、长期治理目标（用户 2026-07-16 追加，PM 纳入治理待办）
1. **端到端先跑通一个健康状态再扩展**（呼应"薄闭环先通"）：大框架(评级器 P1-P4 分支 + 数据 + UI + 免责)完成后，**先定一个慢病(建议高血压——数据最全已 P1 上线)完整跑通端到端**(数据准→评级准→推荐避让→今日卡/餐食卡提示→免责)，验证闭环无误后，**再逐步复制扩展到糖尿病/痛风/高血脂**。避免多病种同时半成品。
2. **食材细化 + 调料等细分后续跟上**：后续细化食材分类与营养(尤其**调料/香辛料**的细分——盐/酱油/油/糖等对钠/油脂/糖指标影响大，家庭"健康饮食"关注度高)；调料营养与用量(SeasoningDefaults 已有默认克数)结合，让"少盐/少油/少糖"提示更准。
3. **全量预设食材/菜品营养可信度持续提升**：目标**所有 440+ 预设食材 + 预设菜品**的营养元素/指标**可信度尽量高、符合营养标准**——不止 §六 的 ≥85% verified 阶段目标，而是**长期逼近全量 verified**(剩确无一手源者标 estimated/pending 并 UI 明示)。菜品营养由其食材营养聚合，故食材 verified 率提升即菜品可信度提升。**这是持续性治理任务，随版本迭代分批核准补全**，PM 长期跟踪覆盖率与可信度指标。
4. **对每个健康状态"深挖·扩展"食材/菜品**：每个慢病维度都要有**足够的适宜/避免食材 + 对应菜品覆盖**，推荐才有料、评级才准。逐病种深挖：
   - **高血压**：低钠适宜食材/菜品(蔬果/杂粮/清蒸白灼)扩充 + 高钠避免(腌腊/咸菜/加工肉)标注齐全；调料侧少盐做法。
   - **糖尿病**：低 GI 适宜(全谷/豆类/绿叶)扩充 + 高 GI 避免(精制主食/含糖)；主食类 GI 数据补齐(批次1)。
   - **痛风**：低嘌呤适宜(蛋奶/多数蔬果/精白米面)扩充 + 高嘌呤避免(内脏/浓汤/部分海鲜)定性清单扩充(P4 已起步)。
   - **高血脂**：低饱和脂肪适宜(鱼禽/植物油/豆制品)扩充 + 高饱脂胆固醇避免(肥肉/动物油/内脏)；依赖 P3 扩 schema。
   - 每病种深挖=**该病种的 care 规则(适宜/限量/避免)覆盖 + 对应营养字段 verified + 有足够对应预设菜品**可推。PM 逐病种拉清单、分批补，与 §三 批次协同。
5. **对健康状态"本身"专业深挖(用户 2026-07-16 强调"要专业")**：不止深挖对应食材/菜品，更要**深入每个慢病的膳食营养科学本身**，基于**权威临床/膳食指南**而非泛化常识：
   - **关键营养因子(逐病种)**：高血压=钠/钾比、DASH 饮食;糖尿病=GI/GL、碳水计量、膳食纤维、餐次分配;痛风=嘌呤来源(动物性>植物性)、果糖、酒精、饮水/碱化;高血脂=饱和脂肪/反式脂肪/胆固醇/可溶性纤维/Omega-3。
   - **权威指南阈值 + 病种亚型/分级**：如高血压分级、糖尿病1/2型与妊娠、血脂各亚型(高TC/高TG/低HDL)——不同亚型饮食侧重不同。
   - **饮食原则模型**：DASH / 低GI / 低嘌呤 / 低脂高纤 等成体系的膳食模式，落到评级规则与 care 建议。
   - **落地**：由**具备临床营养专业度的角色(或权威指南逐条核准)驱动**，评级阈值/care 建议/避让逻辑须**基于专业指南可回溯**，非拍脑袋;数据来源页透明列指南出处。**守免责红线**(仅供参考·非医嘱)。此为一期营养"专业度"的核心保障，PM 牵头引入健康营养专业审校。
