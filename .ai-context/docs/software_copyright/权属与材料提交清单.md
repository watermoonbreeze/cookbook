# 权属与提交材料清单

## 通常需要提交

- 软件著作权登记申请表。
- 申请人主体证明：个人身份证正反面或企业营业执照等。
- 软件源程序鉴别材料：按登记机构要求整理的连续代码页。
- 软件文档鉴别材料：用户操作手册或设计说明书。
- 软件名称、版本号、开发完成日期、首次发表情况说明。
- 自主开发声明；如有合作、委托、受让或继承，附合同或权属证明。
- 代理委托书（委托代理机构办理时）。
- 签字或盖章页。

## 建议一并准备的备查材料

- Android APK 或构建产物校验值。
- 主要页面截图：首启、首页、健康档案、食材、菜品、记餐、食历、营养、库存、周计划、厨房计时、搜索、设置。
- 构建日志、单元测试报告和真机验证记录。
- 版本基线 Git commit：`c9083a0b`。
- 第三方依赖与开源许可清单。

## 申请前必须由申请方补填

- 著作权人和申请人主体信息。
- 联系人、联系电话、地址和证件信息。
- 最终软件名称和版本号。
- 开发完成日期、首次发表日期/未发表声明。
- 权利取得方式及是否存在合作开发者。
- 申请地区、代理机构和盖章要求。

> 具体页数、格式和材料要求以中国版权保护中心或受托登记机构当前规则为准。
