# 家庭膳食管理软件用户功能说明书（MVP）

## 1. 软件定位

家庭膳食管理软件面向有日常饮食管理和慢性病饮食关注需求的家庭用户，将家庭成员健康档案、食材、菜品、餐食记录、营养分析、库存和周期计划组织成一个本地化闭环，帮助用户持续记录和复用家庭饮食。

## 2. MVP功能

### 2.1 家庭与健康档案

- 创建和维护家庭成员档案。
- 为成员记录慢病关注项、饮食忌口和关注维度。
- 在多人家庭场景下按成员切换查看饮食提示和摄入视角。

### 2.2 食材管理

- 浏览、搜索和选择食材。
- 按营养大类和食材分类组织食材。
- 维护食材属性标签、适用人群提示和营养数据。
- 支持用户创建和编辑自定义食材。

### 2.3 菜品管理

- 浏览预置菜品和自建菜品。
- 维护菜品食材、做法、步骤、烹饪方式、餐次和备注。
- 收藏菜品和收藏组合，便于后续复用。

### 2.4 记录一餐

- 按日期和餐次记录早餐、午餐、晚餐及加餐。
- 选择菜品和食材，记录数量、备注及实际食用比例。
- 编辑、复制、删除和撤销整日餐食记录。
- 通过统一入口进入单日手动记录流程。

### 2.5 食历与历史回顾

- 按日期查看历史餐食。
- 使用时间线回顾已记录的饮食。
- 从历史记录和收藏内容复用家庭菜单。

### 2.6 营养与健康提示

- 查看食材营养表和菜品营养卡。
- 查看今日营养卡、热量、营养达标情况和缺口。
- 查看饮食报告、营养趋势和膳食结构提示。
- 基于食材级规则展示慢病相关的宜食、限量和忌口提示。
- 内容用于饮食记录与管理，不替代医疗诊断和医嘱。

### 2.7 库存与采购

- 维护家庭食材库存和可用份数。
- 将库存与计划使用关联，展示缺料和采购需求。
- 查看采购清单并进行家庭备餐准备。

### 2.8 周期计划

- 按周和日期编排手动膳食计划。
- 将计划中的餐食安排复用到实际记录。
- 查看今天及未来计划的统一视图。

### 2.9 厨房工具

- 按步骤进入做菜模式。
- 设置多段烹饪计时器。
- 计时结束后通过系统通知/提醒用户。

### 2.10 搜索、设置与本地数据能力

- 全局搜索食材、菜品和相关内容。
- 首次启动隐私同意和功能引导。
- 主题、偏好和功能开关设置。
- 本地备份导出和双设备选择性同步。

## 3. MVP明确不包含

AI 记餐、云端 GLM 推荐、AI 周计划、AI 健康建议、AI 语音记餐、本地 AI 占位能力不写入本次MVP功能说明。
