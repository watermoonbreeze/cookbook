# 软件著作权申请总览：家庭膳食管理软件 MVP

## 申报定位

本次软件著作权申请只申报 Cookbook 的 Android MVP 核心基础功能，不申报正式一期 AI 增量，也不申报二期外部菜谱解析和商业化能力。

- 建议名称：家庭膳食管理软件
- 申报版本：V1.0（代码构建版本为 0.1.0，材料中需统一口径）
- 运行平台：Android
- 功能基线：c9083a0b
- 产品阶段总表：../projectReview/阶段功能总表.md

## 申报功能范围

### 1. 家庭成员与健康档案

- 家庭成员创建和编辑
- 慢病关注项、忌口和饮食限制
- 成员视角切换
- 每餐成员摄入份额

### 2. 食材管理

- 食材录入、编辑、删除
- 分类和属性标签
- 营养数据
- 食材详情、健康提示和数据来源

### 3. 菜品管理

- 预置菜品和自建菜品
- 菜品食材、用量、做法、步骤和餐次
- 收藏菜品和收藏组合
- 菜品复用

### 4. 记录一餐

- 按日期和餐次记录早餐、午餐、晚餐及加餐
- 选择菜品和食材
- 数量、备注、实际食用比例
- 编辑、复制、删除和撤销

### 5. 食历与历史复用

- 按日期查看历史餐食
- 时间线回顾
- 从历史餐食和收藏内容复用菜单

### 6. 本地健康规则与规则推荐

- 基于成员健康档案和食材属性判定宜食、限量、忌口
- 家庭成员健康提醒
- 按餐次、库存、历史和健康限制筛选候选菜品
- 本地规则推荐、组合评分、去重和多样性
- 推荐结果带入记一餐

### 7. 基础营养分析

- 食材营养表
- 菜品营养卡
- 今日营养卡
- 按食用比例和成员份额折算摄入
- 基础膳食结构提示

### 8. MVP 补充模块

以下模块可以写入说明书的辅助功能，但不是最小核心闭环：

- 库存份数和采购清单
- 手动周计划
- 厨房步骤和计时
- 搜索、设置、主题和隐私引导
- 本地备份导出和选择性同步
- 周/月基础饮食报告和趋势
