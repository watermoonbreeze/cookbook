# 家庭膳食管理软件设计说明书（首期）

## 1. 总体架构

项目采用 Kotlin Multiplatform 的分层结构：`:shared` 保存跨平台 Domain/Data、SQLDelight 数据库、规则和计算；`:androidApp` 保存 Android Compose 页面、ViewModel、导航、主题和平台能力；iOS 工程暂不作为首期交付平台。

## 3. 数据与规则

- SQLite 数据库由 SQLDelight 管理，权威 schema 位于 `shared/src/commonMain/sqldelight/com/sxdbsm/cookbook/db/Cookbook.sq`。
- 预置食材、营养和参考数据通过 resources seed 初始化。
- 摄入计算遵循整份 × 食用比例 × 成员份额的折算关系。
- 健康提示采用食材级 care 规则，并支持宜食、限量、忌口等状态。
- 营养和健康提示属于软件规则结果，不构成医疗诊断。

## 4. 典型业务流程

1. 创建家庭成员和健康关注项。
2. 从食材库选择食材或创建菜品。
3. 按日期、餐次记录实际饮食。
4. 系统保存餐食、食用比例和成员份额。
5. 计算今日营养、膳食结构和健康提示。
6. 将历史餐食、收藏、库存和周计划用于下一餐准备。

## 5. 首期运行环境

- Android 最低 SDK 21，目标/编译 SDK 34。
- Kotlin 1.9.20、AGP 8.2.2、Gradle 8.2、JDK 17。
- Android UI 使用 Jetpack Compose 与 Material 3。
- 首期构建产物为 Android Debug/Release APK。
