# 源程序鉴别材料清单（首期）

## 使用边界

本清单用于整理提交给登记机构的源程序鉴别材料。实际提交页数、首页/尾页规则、是否隐去密钥和内部地址，以登记机构最新要求为准。首期材料应排除 AI 记餐、云端模型、AI 推荐和 AI 周计划代码，保留能完整体现非 AI 家庭膳食管理闭环的连续源程序片段。

## 建议取材顺序

1. `shared/src/commonMain/kotlin/com/sxdbsm/cookbook/domain/`：模型、营养计算、健康规则、周计划、餐食领域逻辑。
2. `shared/src/commonMain/kotlin/com/sxdbsm/cookbook/data/`：Repository、seed、SQLDelight 数据访问。
3. `shared/src/commonMain/sqldelight/`：数据库 schema 和查询。
4. `androidApp/src/main/java/com/sxdbsm/cookbook/android/ui/`：首页、记餐、菜品、食材、家庭、营养、食历、库存、周计划、厨房、搜索、设置页面。
5. `androidApp/src/main/java/com/sxdbsm/cookbook/android/di/`、`platform/`、`MainActivity.kt`：启动、依赖注入和平台适配。

## 排除项

- `shared/.../ai/` 下的云端 AI、AI 记餐和 AI 推荐实现。
- `androidApp/.../ui/ai/`、AI 专属 ViewModel 和 AI 网络配置。
- 仅用于开发治理、全景图、测试报告和临时日志的文件。

## 生成提交页的建议

- 先从上述目录生成带文件路径和行号的源程序汇编稿。
- 按登记机构要求整理为连续页，通常准备前后各 30 页或机构指定页数。
- 每页保留软件名称、版本号和页码；去除 API 密钥、访问令牌、个人隐私和内部服务器地址。
- 另存一份完整源代码归档包，保证鉴别页可以反查到仓库基线 `c9083a0b`。
