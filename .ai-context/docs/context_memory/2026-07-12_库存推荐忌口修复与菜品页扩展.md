# 2026-07-12 会话：库存推荐忌口修复 + 菜品页扩展 + seed 扩充（无人值守）

> 结论性快照，脱离对话可读。

## 一、核心 bug：库存推荐"某食材在库却没推出用它的菜"

- **真因**：不是匹配问题。菜确实进了候选（预筛/按名扩展/库存全正常），是 `HealthRuleEngine` 把**含"忌口(avoid)"食材的菜直接剔除**。用户启用了健康档案（高血脂），**五花肉对高血脂是忌口**，故所有五花肉菜被过滤（实机日志 29 候选→5 评估）。
- **定位手段**：`PantryRec` 诊断日志（gather 打①库存食材 ②预筛候选+命中在手食材 ③库存不足/最近 ④规则评估降序候选 ⑤本批展示）。实机 logcat 一看④就明白。
- **修复（按用户意愿"列出并告知，而非隐藏"）**：
  - 忌口菜不再剔除 → 保留 + `AVOID_PENALTY=50` 排到最后 + `DishCandidate.avoidNames` → UI 行内标红"⛔忌口：X"。
  - **忌口/限量只算非调料**（`nonSeasoning`）：否则"盐对高血压忌口"会让几乎每道菜忌口。`gatherForPlan` 同步排除 `seasoningIds`。
  - **调料的忌口/限量转做法提示**：`cookingCautions`（盐→少盐/白糖→少糖/生抽→少酱油/油→少油），UI 显示"🧂做法建议"。
  - 物尽其用排序：`ON_HAND_MAIN_BONUS=1.0`（用到在手主料强力提权）；`SHORTAGE_PENALTY 100→0.3`、`MISSING_PENALTY 50→0.2`（份数不足/缺辅料不再断崖埋菜）。
