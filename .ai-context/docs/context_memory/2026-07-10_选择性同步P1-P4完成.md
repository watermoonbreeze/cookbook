## 成果
- **机制**：全部=整库替换(现状)；选择性=按名称匹配合并+ID重映射。接收端**自动识别**(zip 含 `data.json`=合并；含 `cookbook.db`=整库替换)，传输层(socket/二维码)不变。
- **数据域**：菜品/食材/库存/健康档案/收藏/餐食历史；选某域**自动带依赖**(库存→食材, 收藏/餐食→菜品+食材)。
- **合并键**：食材/菜品/标签=name(食材同名复用不覆盖、菜品同名更新)；库存=按食材名覆盖份数；健康=按人群名启用；收藏=按名(同名跳过)+菜品名重映射；餐食=按(date,餐次code)替换。
- **UI**：发送前"选择同步内容"(全部覆盖/具体域合并, **每项带说明**, 顶部标注覆盖vs合并)；弹框整体可滚动。
