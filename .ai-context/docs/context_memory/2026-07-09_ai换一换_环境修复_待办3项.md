## 构建环境坑（重要，已存全局记忆 android_gradle_android_sdk_home_conflict.md）
- **根因**：用户环境变量 `ANDROID_SDK_HOME=D:\DevEnv\Android`（已废弃）与 `ANDROID_USER_HOME=D:\DevEnv\Android\avd_home` 指向不同路径 → AGP 8.2.2 报 `AndroidLocationsException`，构建崩。`gradlew --stop` 后新守护进程读到冲突变量才暴露。
- **临时**：每个 gradle 命令前 `unset ANDROID_SDK_HOME;`（Bash 工具每次重读 profile，故每次都要带）。
- **根治**：用户删除 `ANDROID_SDK_HOME` 用户变量 + `--stop` 守护进程 + 开新终端（IDE 需重启）。**用户正在删，删完需重验构建不再带该变量**。
- 保留的正确变量：`ANDROID_HOME=...\Sdk`、`ANDROID_USER_HOME=...\avd_home`、`ANDROID_AVD_HOME`。
