## 关键经验（详见经验手册）
- **多 init 加载器并发 + 全量快照 copy 写回 = 字段被冲掉**：`val x=_state.value` 捕获后经挂起再 `_state.value=x.copy()` 会丢并发更新的字段。修法：`_state.value.copy` 或 `_state.update{}`。
