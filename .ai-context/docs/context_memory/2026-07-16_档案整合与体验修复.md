# 上下文快照：档案整合 + 拍照方向/角标/导航栏 体验修复（2026-07-16）

> 用户报的一批体验调整,已全部落地+推送(gitee master 到 e5af7e3)。

## 一、已落地(均 commit+构建过,已 push)
1. **小米8拍照90°旋转** — 相机方向只写EXIF、像素不转,直接BitmapFactory解码会偏。加 `androidx.exifinterface` 依赖,`readExifOrientationMatrix`读TAG_ORIENTATION,`applyMatrix`解码后按方向摆正再保存(存摆正像素,读取处无需再转),覆盖90/180/270/翻转/转置。文件 `ui/component/ImagePickerButton.kt`。
2. **主食角标** — 由左上角圆角三角改苹果式贴角小圆(16dp CircleShape+9sp"主")。`ui/component/MealDishGrid.kt` StapleBadge。
3. **个人健康档案→家庭档案整合**(与用户商定):
   - 取消独立"个人健康档案"入口/HealthProfileDialog;我的"健康"组→"档案"组,入口=家庭档案(onOpenFamily→Routes.FAMILY)。
   - 家庭档案从功能设置提到我的顶层(删FeatureSettingsScreen的家庭EntryRow)。
   - 用户卡标签数据源:旧`profiles`(HealthProfileRepository)→`MineViewModel.healthCard`(家庭成员"我"is_self的careCategoryIds映射名);整卡可点进家庭档案;关注成员≠我时"当前关注:XX"。MineViewModel加FamilyRepository依赖(DI改6参)。
   - 家庭成员"病种"→"健康状态"(FamilyScreen文案;选项不变、本就同套CrowdType/care、已挂忌口调养)。
   - **数据层HealthProfileRepository保留**(legacy忌口仍`allEnabledCareIds`并集,向后兼容),仅UI不再单列。
4. **导航栏色跟随界面** — 原透明系统栏在"app深色但系统仍浅色"时,全屏页navigationBarsPadding区露android默认白windowBackground(styles.xml AppTheme无覆盖)、割裂。改CookbookTheme内SideEffect把statusBar/navigationBarColor设为`colorScheme.background.toArgb()`(明暗自适应,浑然一体)。`MainActivity.kt`。

## 二、关键认识/坑
- **个人健康档案与家庭成员"我"本是同一套care分类**(CrowdType:三高/痛风),忌口/调养统一走care;整合是纯UI入口去重,数据层不动、低风险。
- **拍照EXIF方向**:部分设备(小米/华为)方向写EXIF不转像素→需androidx.exifinterface读取+Matrix摆正(android.media.ExifInterface的InputStream构造要API24,minSdk21用androidx版更稳)。
- **透明系统栏≠跟随界面色**:android默认windowBackground(styles.xml未覆盖)在app主题≠系统主题时会露出→需显式设navigationBarColor=Compose主题背景。
