## 关键决策（为什么这么做）

1. **Box 叠加而非 bottomBar 槽 hack**：槽高恒压进 content padding（=margin），负 offset/零高包装依赖 Scaffold 内部实现且越界不参与命中测试。
2. **contentPadding 而非 modifier padding**：modifier 裁短视口失去穿透；contentPadding 不占 item index（字母跳转安全）。
3. **双口径**：滚动容器用 reservedTotal（82+inset）；自带 navigationBarsPadding 的底栏式组件（SelectionSummaryBar）用 BodyHeight（82）防双份 inset。
4. **不做 hide-on-scroll**：iOS Tab Bar 从不因滚隐藏；家庭高频切 Tab+适老常驻可达。
5. ⚪ 已知非回归遗留：搜索覆盖层不避让 IME（改造前同样）、二级页 Snackbar 贴屏底（与改造前一致）——留作后续打磨。
