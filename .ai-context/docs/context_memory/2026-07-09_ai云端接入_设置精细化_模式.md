## 关键修复：云端推荐一直回退规则的根因
- **缺 `INTERNET` 权限**：本地优先 App 从没联网，Manifest 没声明 INTERNET → CloudAiRuntime 的 HTTP 被系统拒 → 每次回退规则、"AI设置感觉没生效"。已加 `INTERNET`+`ACCESS_NETWORK_STATE`（commit `4c56aef`）。改 Manifest 权限**必须重装 APK**。
- 排查法：用用户 key `curl` 智谱接口验证——通了(鉴权OK/格式匹配)就说明问题在 App 端(权限/配置)。智谱 v4 接口 `Authorization: Bearer <原始apikey>` 直接可用(无需手动 JWT)；响应 `{choices:[{message:{content}}]}`。
