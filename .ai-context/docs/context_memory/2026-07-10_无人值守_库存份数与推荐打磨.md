- **#3 库存推荐放宽** `5203d2a`：查清**无"≥2菜"过滤**(不存在)；红烧肉不出现真因=`HealthRuleEngine.evaluate` 要求**全部非调料食材齐**(`nonSeasoning.all{在手}`)才可做，五花肉齐但辅料没齐→整菜被 mapNotNull 丢。改为**主料齐即可推荐**(无主料菜按非调料齐兜底)；缺辅料记 `DishCandidate.missingNames`、`MISSING_PENALTY` 降权、推荐面板/AI prompt 标"🛒还需采购"。engine/model/prompt/VM/单测同步。
