### agent prompt 模板（把 `_N_` 换成分片号）
- 角色：营养数据权威核准工程师，联网核对，不改源码。
- 输入：Read `temp/claude/nutriverify/pending_shard__N_.json`。
- 口径：每 100g 可食部；kcal 千卡，protein/fat/carb/fiber/satFat 克，sodium/potassium/calcium/cholesterol/purine 毫克(purine mg/100g)，gi 指数(FAO/WHO)，pieceGram 每个/份克重。

- 输出 JSONL：`temp/claude/nutriverify/out_shard__N_.jsonl`，**每核准完 1 条即写盘**(Read 现有→加行→Write，内存不囤超 1 条)；**断点续连**：开工先 Read out 文件跳过已写 ingredient；每行=完整更新营养对象(原字段原样带+改的覆盖+新的补)+ `_srcnote`+`_fields_checked`。最终消息只回：完成数/verified/pending 各几/查不到名单/权威来源去重清单。
