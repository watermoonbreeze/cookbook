## 一、苹果风格 UI 改造（Phase0 设计token + UX设计师5轮测试，已完成验收）
- 方案文档：`.ai-context/docs/feature/苹果风格UI设计方案.md`（配色/字体/间距/组件/交互/落地路线）。
- **设计 token**（`ui/theme/`）：单一强调色**赤陶橘**（primary=tertiary=`#DC6E3C`亮/`#F0895A`暗）贯穿所有可交互元素；暖中性灰骨架（分组底 `#F5F2EE`、白卡、细分隔 `#E1DAD0`）；字体对齐 iOS（正文 17、列表标题 17 半粗、大标题 34，`Theme.kt` Typography）；圆角 12/16/20；语义色（success/warning/danger）克制。
- **新增组件库**（`ui/component/`）：`SegmentedControl`、`CapsuleButton`、`InsetGroup`/`InsetDivider`、`ActionSheet`(+`SheetAction`)、`PlainCard`、`MiniStepper`。
- **5 轮 UX 落地**：R1 大标题(首页/我的 LargeTopAppBar)+顶栏 tint 统一 accent+胶囊保存；R2 设置页分组内嵌白卡+去描边+inset分隔+列表 chevron；R3 长按→ActionSheet+iOS步进器+删除红字；R4 卡片去阴影(PlainCard)+首页去大色块+空态/间距/语义色收敛；R5 终审收口(残留控件全清/tint语义统一/圆角一致)。
- 交互原则：单一 tint、内容优先、分组内嵌列表、破坏操作走 ActionSheet/红字、合理默认、渐进披露。**真机视觉待用户确认**。
- 剩余长期打磨(B组)：`OutlinedTextField`→inset输入、token pill、更多选择器 sheet 化。

## 二、控件打磨（B组，用户明确"以后按这套走"）
- **MiniStepper**：−/＋ 缩小成可点 tint 标签(不再大按钮)，**统一所有步进器**（克数/份数/人数/入库/采购）。
- AI 周期计划(`AiPlanScreen`)：天数=标签+周期快捷一行(可横滑)、slider 右侧显示"N天"、用餐人数(MiniStepper)与「生成」同一行；控件并入同一 LazyColumn 头部→生成后上滑整体滚走给计划更大空间；"规划天数"→"天数"(让"一月"按钮显示全)。

## 三、餐食卡片（DayMealCardView，按用户方案）
- 日期与操作**同一行**：紧凑日期(**本年只月日、非本年加年份**)+今天/计划**角标**(小胶囊)+右侧复制/编辑/删除图标(删除红)。去掉了竖排操作列。
- 复用于 首页/食历/一周计划/搜索；WeekPlan 之前漏删除已补(deleteDay+确认)。

## 四、营养色系（功能设置开关 `NUTRITION_COLOR_ENABLED`，默认关）
- 级别口径：`FoodGroup.nutritionLevel(groups)` 0~4（三大支柱 蛋白/主食/蔬果 覆盖度+多样性）；`nutritionLevelLabel`。
- 配色(`ui/component/NutritionColor.kt`)：**每级一个基色**（琥珀→黄绿→浅绿→绿=单一→均衡）；**卡片背景=低透明度**(向白底淡化，浅、文字可读，防撞色)、**色系墙=满色**（同基色，仅透明度不同——用户约定）。
- **首页「营养色系墙」**(`ui/home/NutritionWall.kt`)：GitHub 热力图式，每列一周、横向可滚动看全部历史(默认到今天/满宽)、**纵轴星期(左固定 一~日)+横轴月份(列顶 N月)**、今天格描边、**点色块跳到那天**、图例。数据 `HomeViewModel.nutritionWall`(dateRange 定起点→observeTimelineWindow 每天算级别，整周对齐)。
