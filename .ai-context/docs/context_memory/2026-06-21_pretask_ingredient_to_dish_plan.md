# 食材关联做法/菜品推荐方案任务前快照

- 时间：2026-06-21
- 用户需求：在食材维度重构基础上，规划“食材和做法关联起来”的能力，例如用户手上有青椒、鸡胸肉时，可以关联/推荐能做什么菜。
- 任务类型/深度：Research + Feature 方案，标准级。
- 计划角色：主线程模拟 DEV_PM、DEV_ARCH、DEV_DB、DEV_UI、DEV_REVIEW；不进入代码实现。
- 已知项目状态：已有 `dish_ingredient` 表表达菜品与食材多对多关系，`DishRepository.searchDishes` 已能按食材名搜索菜品；任务10新增了菜品操作步骤 `dish_step`。
- 预计涉及模块：食材页、菜品页、搜索/推荐、`dish_ingredient` 查询、未来可能的 AI 推荐。
- 主要风险：仅用“包含任意食材”会推荐噪音大；需要区分“我有的食材”“缺少的食材”“主料/辅料/调味料”和做法复杂度。
- 待验证项：后续是否需要支持按操作步骤/烹饪方式/慢病限制共同筛选。
