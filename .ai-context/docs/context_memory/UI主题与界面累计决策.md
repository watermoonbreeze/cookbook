# UI 主题与界面累计决策

> 更新时间：2026-05-19

## 主题与配色（已落到 `docs/技术栈与主题风格.md`）

- **绿色主调 + 蜂蜜橙暖色辅助**，避免医院/养生冷感
- Primary 绿 `#4A6741`；Tertiary 蜂蜜橙 `#825500`（取代原青绿 `#386663`）
- **Extended Colors 语义色独立预留**：Success / Warning / Danger（Light + Dark 各一套）
- **MVP 同步上线 Light + Dark + 主题切换**（三档：跟随系统/浅色/深色）
- 主题切换入口：原计划 ⋮ 菜单，**2026-05-19 已迁移**到 MineFragment

## 关键配色约定

- `Tertiary` 暖橙 = **品牌强调**（收藏组合 / 复用 / 导入 / `#复制` 标签 / 喜爱度星星）
- `Warning` 暖橙 = **业务警告**（中风险食材角标，色值更亮）
- `Error` 红 = 系统级错误（输入校验）；`Danger` 红 = 健康业务级禁忌
- 两者色值在主题文档已区分，避免混淆

- HomeFragment：搜索 + 热门 + 最近 + 计划（两条）
- FoodTimelineFragment：时间轴 + 15 天分页列表 + 联动滚动
- AddDayFoodActivity：统一录入页（选日期 + 餐次 + 菜品）
- DishesFragment：浏览模式 + 选择模式（DialogFragment 内嵌时切换）
- MineFragment：主题 / 健康档案 / 备份 / 关于 / 厨房小助手
