## 关键约束/事实
- dishes.json 结构：`{code,name,method,description,ingredients[{ingredient(名),main,quantity,unit}],steps[str]}`。seeder 按名解析：method→`methodIds[name]`、食材→`selectIngredientIdByNameIncludingInactive`、unit→`unitIds[name]`，**解析不到静默跳过**。已存在预设菜按名跳过不覆盖。
- 有效烹饪方式(DB seed 全集)：炒/蒸/煮/炖/烤/凉拌/煎/炸/焖/卤。有效单位：克/两/斤/毫升/升/个/片/勺/颗/把/碗/块/根/条/段/瓣/只/适量/少许。
- 已有厨房计时器是独立持久化页(`CookingTimerScreen`+`CookingTimerService`+`TimerAlarm`)；Cook Mode 的内嵌计时是轻量自包含版(不接持久化服务)，靠 KEEP_SCREEN_ON。
- seed 指纹变化→重跑，真机需**重装 APK** 才能看到 22 道新菜。
