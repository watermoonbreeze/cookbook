## 方向2：每日卡路里目标 + 达标评定
- **2a 身体数据+目标**：`domain/model/HealthMetrics.kt` = `BodyMetrics`(性别/身高/体重/年龄/活动) + `CalorieTarget`(Mifflin-St Jeor BMR×活动系数→每日目标，数据不全返 null) + `CalorieStatus`(达标/偏低/超标，目标±15%)。身体数据存 `user_preferences`(`BODY_METRICS` JSON，**免迁移**)；`PreferenceRepository.observe/setBodyMetrics`。功能设置加「每日热量目标」录入区(`FeatureSettingsScreen.BodyMetricsSection`)：性别/活动分段 + 身高/体重/年龄输入 + 目标即时预览 + 免责。单测 `CalorieTargetTest`。
- **2b 餐食达标**：`DayMealCardView` 当天热量行附「/目标X·达标/偏低/超标」(填了身体数据才显示；达标=primary/超标=error/偏低=灰)。
- **2c 色系墙评级**：`HomeViewModel.nutritionWall` 改 `combine(timeline,bodyMetrics)+mapLatest`，有目标时当天热量偏离(偏低/超标)则营养级别降一档(`maxOf(1,level-1)`)；未填身体数据行为不变。

## 方向3：推荐收尾 + 营养数据
- **3a 推荐 prompt**：`RecommendationPrompt.build` 加 `style`+`preferenceScores`/`nutritionBalanceScores`：system 按风格给指令，候选行标「常做」「补营养」。Orchestrator 透传。
- **3b 逐菜理由**：`DishCandidate` 加 `frequent`/`complementary`(引擎按 preference≥0.5 / balance>0 置位)；`AiRecommendViewModel.buildNote` 前置「⭐你常做」「🥗补营养搭配」。
