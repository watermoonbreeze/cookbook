# AI 记一餐日期锚点与确认页修复

- 任务：修复确认页底部操作/查看建议被裁切，以及 AI 记餐忽略添加页所选日期的问题。
- 模式：标准任务；用户已授权无人值守，本地提交可用但不自动推送。
- 已知：AI/规则均已接收 `targetDate`，但 AI 可能输出当天的虚构绝对日期，转换层会优先采纳它。
- 决策：以添加页日期为唯一锚点；输入含绝对日期时才允许覆盖；仅有星期按锚点所在周计算；无日期时全部回落锚点并只给一条提示。
- 涉及：`AiMealInputSheet`、`AiMealInputViewModel`、共享解析/日期规则、单测、真机清单与项目说明书。
