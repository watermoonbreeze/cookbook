## 自主决定的事项（请审核）

### A. 技术决策

| # | 自主决定 | 影响 | 可改 |
|---|---------|------|------|
| A1 | **iOS targets 暂时禁用**（已注释 `kotlin{}` 中 iosX64/iosArm64/iosSimulatorArm64） | 无：MVP 不做 iOS。iosMain 源码已移到 `/tmp/cookbook_ios_backup/`，一期启用 target 时再迁回 | 易 |
| A2 | **热度累加由应用层维护**（而非 SQL TRIGGER） | SQLDelight 当前方言不支持触发器 NEW 引用。改在 `MealRecordRepository.save()` 写入 meal_record_dish 后调用 `incrementDishPreference()`。逻辑等价 | 中：未来切方言可恢复触发器 |
| A3 | **`user_preferences.upsertPreference` 用 INSERT OR REPLACE** 替代 ON CONFLICT | SQLDelight sqlite-3.18 方言不支持 UPSERT 语法。语义等价 | 易 |
| A4 | **删除了 `selectDishesByPinyin` 中的 REPLACE 函数调用**（改为 `ORDER BY name`） | 该查询当前未被引用 | 易 |
| A5 | **Compose Compiler 升级 1.5.4 → 1.5.6** | 与 Kotlin/Native 拉下来的 1.9.21 兼容 | 易 |

## 修复过的编译错误（共 6 类）

1. **iOS Kotlin/Native 编译器下载超时** → 禁用 ios targets
2. **SQLDelight sqlite-3.18 不支持 REPLACE 函数** → 删除该查询用法
3. **SQLDelight 不支持 UPSERT** → 改为 INSERT OR REPLACE
4. **SQLDelight 不支持触发器 NEW 引用** → 改应用层维护
5. **koin-androidx-compose 版本号错** → 改为同 koin 主版本
6. **Compose Compiler 与 Kotlin 版本不匹配** → 升 1.5.4 → 1.5.6
7. **HorizontalDivider / Icons.AutoMirrored 是 Compose 1.6+** → 改回 1.5 API
