## 核心规则

- 顶部主分类固定为：最近、常规、营养、调养、自定义。
- 最近使用只放在最近 Tab。
- 管理分类只放在自定义 Tab。
- 自定义是用户创建分类和用户创建食材的聚合视图，不是隔离分类体系。
- 用户创建分类可挂载到常规/营养/调养任意节点，同时在自定义中聚合展示。
- 用户创建食材可多选常规/营养/调养/自定义分类，并同步展示到对应分类。
- 新增/编辑食材改为完整页面或全屏 Sheet，不沿用旧弹框。
- 食材展示名称统一为 `名称(别名)`，别名为空只显示名称。
- 菜品选择食材与食材页统一使用 `IngredientBrowser`，不保留旧选择逻辑。
