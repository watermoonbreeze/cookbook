# BLUEPRINT LEVEL STANDARD

本项目当前颗粒度基线为 L7；Level 是 ARCH 为执行模型消除的决策空间，不是风险等级、模型等级或自动路由开关。定义与 GC 真相源仍是 `~/.ai-context/rules/blueprint_protocol.md` §2.1/§2.2 及本项目 `12_多模型协作与实施蓝图规范.md` §12。

## L1→L7 阶梯

| Level | 决策空间闭合主题 | 最小可检查结果 | 典型工件 |
|---|---|---|---|
| L1 | 决策与范围 | 分支、allowlist、禁止项和延后项有唯一归宿 | 任务卡、范围表 |
| L2 | 证据 | INV/T/E/Q-AF 可逐项回指命令或文件 | 测试矩阵、证据台账 |
| L3 | 真相源 | 字段唯一写入者、协议两端和调用路由闭合 | 数据流/真相源表 |
| L4 | 所有权与生命周期 | 资源、并发、取消、身份重校验有明确 owner | 生命周期/时序表 |
| L5 | 索引空间与集合投影 | 序号、过滤、映射的索引空间逐项声明 | 投影/集合表 |
| L6 | 用户可见副作用 | 丢弃、截断、纠正、文案与节流均有落点 | UI 副作用矩阵 |
| L7 | 脚本可勾销 | 每个最小动作有 STEP 和字面完成形态，可机械核对 | STEP 清单、allowlist、审查表 |

## 示例映射

| 任务类型 | 推荐声明 | 依据 |
|---|---|---|
| 纯文档/治理 | L7 基线可按不适用 GC 标 `N/A`，不得省略状态/证据门禁 | 01~07 夜间治理批次 |
| 结构化日志契约 | L7；需事件字典、脱敏不变量、自动测试和真机证据登记 | OVN-01~03，`fc842a41`/`606ac9c5` |
| UI/业务跨模块变更 | L7；不得因“只改 UI”下调，除非状态表明确给出降级理由 | 项目既有 L7 蓝图基线 |
| 新模型首次执行 | 仍按项目 L7；增加 allowlist/evidence 机械复核，不降低 Level | `experience/14_模型执行力评估.md` 零样本处方 |

## 使用与升级边界

- 任务设计：先声明 Level，再按条款集合建立蓝图勾销表；不以风险高低替代颗粒度。
- CODE 评估：Level 只描述蓝图约束强度；执行偏差按 `OMISSION/SCOPE/SURFACE/INTEGRITY` 归因，不自动升级 Level。
- 模型选择：本表只供复核强度参考，不覆盖 `MODEL_ROUTING`，不修改模型配置。
- 当前不新增 L8；只有真实批次出现现有 GC 无法表达的新决策空间，才按项目决策门重新评估。
