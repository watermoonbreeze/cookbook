# 缺席状态与审核证据经验

## 2026-08-27 · Bug-3393 / Bug-2119

- 含“今天”语义的统计，必须把当天投影与历史窗口分开计算、分开断言；今天的缺席集合不能改变过去日期的份额。
- 真实 SQLite/Repository/ViewModel 测试不得假定领域默认值。成员饭量系数等会影响数值的字段，须显式设定或由夹具值推导期望。
- “非零”不是充分的回归断言。成员份额修复至少覆盖：全员在场的精确分摊、缺席者归零、在场者承接、历史日不回归、全家汇总不回归。
- 审核启动即写增量台账；每个 AF 记录定位、证据、最小修复与复验结果。中断后的审核者从最后一条未关闭项续查。
- 自动化验收与真机验收分离：单测、构建、allowlist 和独立审查通过后可标 `AUTOMATED_GATES_PASS`，设备项仍必须保持 `PENDING_DEVICE_VERIFICATION`。
