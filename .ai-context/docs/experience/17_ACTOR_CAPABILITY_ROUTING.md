# ACTOR_CAPABILITY_ROUTING

本文件是项目内执行经验的反查矩阵，不替代全局 `MODEL_ROUTING`，也不修改实际模型配置。结论只描述已记录批次的观察，不等同于模型的普遍能力结论。

## 能力维度

| 维度 | 记录口径 |
|---|---|
| Blueprint Level 适配 | 在已记录任务族中，蓝图约束是否被机械执行；样本不足时写“未形成结论” |
| 独立推理能力 | 是否能在无实时纠偏下完成范围内分析/实现；只引用具体批次事实 |
| 越界风险 | 是否出现 allowlist 外改动、未授权业务修改或证据越界；没有证据不判定为低风险 |
| 返工率 | 以记录中明确的 rework/阻断轮次计算；缺少统一分母时只列事实，不计算百分比 |

## 路由建议边界

- 本矩阵只提供“复核时应加哪些证据”的建议，不自动选择模型、不改配置、不覆盖 `MODEL_ROUTING`。
- 新模型或新任务族样本为 0 时，沿用项目基线，并加做 allowlist/evidence 机械检查；不能据此降低 Blueprint Level。
- 只有至少 3 个同类批次且证据口径一致，才允许在此文档增加观察性趋势；仍需保留混杂因素说明。
