## 一、一般人群（膳食指南 2022 · 八条准则）
1. 食物多样，合理搭配（谷类为主）
2. 吃动平衡，健康体重
3. 多吃蔬果、奶类、全谷、大豆
4. 适量吃鱼、禽、蛋、瘦肉
5. 少盐少油，控糖限酒
6. 规律进餐，足量饮水
7. 会烹会选会看标签
8. 公筷分餐，杜绝浪费

### 关键每日量（headline 值，以原文为准）
| 项 | 建议量 |
|---|---|
| 食盐 | < 5 g |
| 烹调油 | 25~30 g |
| 添加糖 | < 50 g（最好 < 25 g） |
| 蔬菜 | 300~500 g（深色占一半） |
| 水果 | 200~350 g |
| 全谷物和杂豆 | 50~150 g；薯类 50~100 g |
| 奶及奶制品 | 300~500 g |
| 鱼禽蛋瘦肉（动物性食物） | 每日约 120~200 g |
| 饮水（成人） | 1500~1700 ml |

> 对照用法：营养维度标签「优质蛋白/高膳食纤维/深色蔬菜/全谷物/高钙」等即对应上述鼓励项，周期规划营养均衡按这些维度铺开。

## 二、慢病膳食原则（按 App 健康档案病种，原则性摘录）

> 每条给「核心原则 + 鼓励(RECOMMEND) + 限制(LIMIT) + 避免(AVOID) 方向」，作为 `crowd_ingredient` 规则校订的对照。具体阈值以专科指南/医嘱为准。

### 高尿酸血症与痛风
- 核心：低嘌呤、多饮水、限酒（尤其啤酒/白酒）、控体重。
- 鼓励：低嘌呤食物（多数蔬菜、蛋、奶）、充足水分。
- 限制：中嘌呤（部分鱼肉禽、豆类适量）。
- 避免：高嘌呤（动物内脏、浓肉汤、部分海鲜）、含糖饮料/果糖、酒精。

### 2型糖尿病与血糖异常
- 核心：控总能量、低 GI/GL、定时定量、主食粗细搭配。
- 鼓励：低 GI 主食（全谷杂豆）、高膳食纤维蔬菜、优质蛋白。
- 限制：精制碳水、添加糖、高 GI 水果适量。
- 避免：含糖饮料、糖果甜点。

### 高血压
- 核心：低钠（DASH 模式）、富钾、控体重、限酒。
- 鼓励：高钾（多数蔬果、薯类）、低脂奶、全谷、优质蛋白。
- 限制：高钠加工食品、腌制品。
- 避免：过量食盐/酱油/咸菜、过量酒精。

### 高脂血症（血脂异常）
- 核心：控饱和脂肪与反式脂肪、增膳食纤维、控体重。
- 鼓励：膳食纤维、深色蔬菜、鱼类(ω-3)、全谷。
- 限制：胆固醇偏高食物适量。
- 避免：油炸/肥肉/动物油、反式脂肪（部分糕点/植脂末）。

### 慢性肾脏病（CKD）
- 核心：优质低蛋白、限钠、按分期限钾限磷（需专科指导）。
- 鼓励：优质蛋白(适量)、低钠。
- 限制：蛋白总量、（进展期）高钾高磷食物。
- 避免：高钠加工食品；具体限量强依赖分期与医嘱。

### 其他（待扩充）
- 非酒精性脂肪肝、冠心病与动脉粥样硬化、骨质疏松症、慢性胃炎与消化性溃疡、慢性肠道疾病、慢性便秘 …… 按需追加（对应 food_category `crowd` 维度已有病种节点）。

- App 推荐/规划：有档案时优先 RECOMMEND、保≥80%利健康，忌口(AVOID)硬剔除、限量(LIMIT)降权。
