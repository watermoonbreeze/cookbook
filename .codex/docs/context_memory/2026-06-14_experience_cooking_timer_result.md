# 烹饪计时经验总结结果

- 时间：2026-06-14
- 用户需求：总结烹饪计时相关经验。
- 写入位置：`.codex/docs/experience/03_数据库.md`。
- 数据库经验：烹饪计时只持久化模板配置，不持久化运行态、暂停态、完成告警态、剩余秒数和正在播放的 `Ringtone`。
- 数据库经验：计时模板展示顺序使用 `sort_order, id` 稳定排序，不跟随运行状态重排；新增工具型配置表仍需完整走 schema、迁移、Repository、测试、文档同步。
- 写入位置：`.codex/docs/experience/05_UI组件.md`。
- UI 经验：计时类列表不要按运行/完成状态自动置顶，避免倒计时过程中列表跳动。
- UI 经验：响铃必须保存 `Ringtone` 实例并在点击记录、停止按钮、页面退出或实例替换时主动停止。
- UI 经验：完成态使用明显红色提示，确认后恢复普通状态；时长输入拆为“分 / 秒”两个字段更适合移动端。
