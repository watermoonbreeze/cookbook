# 2026-05-24 头部筛选与食材 emoji 调整记录

- 食材无图片时使用 `foodEmojiForName()` 根据食材名称匹配默认 emoji，匹配不到使用通用食物 emoji。
- 食材选择项不再显示明显“预设/自建”文字：
  - 预设食材保持默认展示，不响应长按。
  - 自建食材显示一个更多操作小图标，提示可长按编辑/删除。
- 菜品页头部固定为“菜品 + 搜索 + 添加”，搜索框与标题并列。

- 菜品页筛选补齐：
  - 最近：沿用列表默认最近更新顺序。
  - 喜爱：按 preference 降序。
  - 拼音：当前先按名称排序。
  - 全部：按 id 升序。
- 首页头部固定为“今天吃什么 + 搜索 + 主题切换”，热门/最近/计划整体滚动。
- 验证命令：`./gradlew :androidApp:compileDebugKotlin`、`./gradlew :androidApp:assembleDebug`，均通过。
