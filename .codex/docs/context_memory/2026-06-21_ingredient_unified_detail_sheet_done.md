# 食材浏览统一详情弹层修复完成

- 时间：2026-06-21
- 类型：BugFix / UI 交互统一
- 需求：首页食材 Screen 与菜品添加食材选择器复用同一套食材浏览逻辑，差异仅保留“是否可选择”和“是否显示底部已选栏”。

## 本次结论

- 已移除食材管理页右侧详情面板逻辑。
- 点击任意食材卡片统一打开底部详情弹层。
- 底部详情弹层高度为屏幕 65%，内部详情内容可上下滚动。
- 弹层顶部左侧固定显示“取消”。
- 仅在菜品选择食材模式下，弹层顶部右侧显示“选择”按钮。
- 选择模式下点击“选择”后加入已选并关闭详情；已选择食材再次打开详情时按钮显示“已选择”且不可重复添加。
- 底部“已选 N 项 / 添加食材 / 完成”栏仅在选择模式且已有食材被选中后显示。
- 食材名称在详情中按“名称(别名)”规则展示。
