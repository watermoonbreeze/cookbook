# 2026-06-04 status 软删除字段审计任务前上下文

- 用户要求：检查所有数据表是否都有 `status` 字段。
- 字段语义：`status` 用于标识数据是否有效，0=无效，1=有效，默认 1。
- 后续所有删除操作应改为软删除，只设置记录 status，方便后续排查和查看操作记录。
- 风险：这是 schema 级架构调整，会影响 SQLDelight schema、迁移文件、所有 select/delete 查询、外键关联和历史数据。
- 本轮策略：先审计现有所有 CREATE TABLE 和 delete 查询，确认缺失范围，再做分阶段实现建议；如直接落地，优先从主业务表和用户可删除表开始。
