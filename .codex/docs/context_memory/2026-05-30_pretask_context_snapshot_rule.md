# 2026-05-30 任务前上下文快照规则修正

## 用户问题
- 用户指出：现在每次执行任务前没有进行保存上下文操作。

## 原因结论
- 原有规则只强制“任务开始前做阶段0编排声明”和“重要节点完成后保存上下文”。
- 没有把“阶段0后、阶段1前保存任务前上下文快照”写成门禁，所以执行时被当成收尾动作。

## 本次修正
- 更新 `~/.codex/memories/workflow_auto_orchestration.md`：
  - 阶段0声明后、阶段1分析或实质操作前，必须保存任务前上下文快照。
  - 快照至少包含最新需求、模式/级别、计划分派、已知状态、预计文件、风险和待验证项。
- 更新项目 `AGENTS.md`：
  - 在上下文保护机制中加入任务前快照规则。
- 更新 `.codex/docs/experience/06_问题与踩坑.md`：
  - 记录“任务前上下文快照不能只靠收尾保存”的经验。

## 后续执行规则
- 后续所有会执行命令、修改文件或产生项目决策的任务，都先声明编排，再写任务前上下文快照，再进入分析/实现。
- 纯问答可以不写快照，但必须说明原因。
