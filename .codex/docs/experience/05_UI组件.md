# UI组件

## Picker 组件模式

[2026-05-24]
- `DishPickerScreen`：全屏 Compose `Dialog(usePlatformDefaultWidth=false)`，支持多选/单选、搜索、最近常吃、热度横滑、列表选择。
- `AddDayFoodScreen` 使用 DishPicker 多选，回调到 `AddMealViewModel.addDishes()` 合并去重。
- `NewDishScreen` 使用 DishPicker 单选导入，回调到 `NewDishViewModel.importFromDishId()`，复用 `importFrom()` 并自动追加 `#复制` 标签。
- `IngredientPickerScreen`：全屏 Dialog，支持分类树、食材网格、跨搜索/分类保留选择、排除已选食材。
- `IngredientPickerScreen` 底部“添加食材”使用 `AlertDialog`，创建成功后自动选中新食材。

## 菜品详情页

[2026-05-24]
- 新增 `DishDetailScreen` / `DishDetailViewModel`，补齐 `Routes.DISH_DETAIL` 的实际路由。
- 详情页展示热度、标签、食材、烹饪方式、特殊说明、描述，并提供编辑入口。
- Dishes 列表点击进入详情，长按“基于此另存”进入 `NewDishScreen(importDishId=...)`。

## Android 应用名

[2026-05-24]
- Android 显示名使用资源 `@string/app_name`，值为 `CookBook`。
- 不直接在 Manifest 写死字符串，便于后续多语言和统一管理。
